  <name>Task 1: Replace NutritionSummaryCard progress bars with circular rings</name>
  <files>JabTracker/Views/Nutrition/NutritionSummaryCard.swift</files>
  <action>
    **Replace the horizontal progress bar layout with circular progress rings:**

    1. **Keep existing header** (lines 27-34) - "Today's Nutrition" with fork.knife icon

    2. **Replace macroProgressRow VStack** (lines 41-73) with HStack of 4 CircularProgressRing components:
       ```swift
       HStack(spacing: 16) {
           macroRing(label: "Calories", consumed: totals.calories, goal: user.dailyCalorieGoal, defaultColor: .orange, unit: "kcal")
           macroRing(label: "Protein", consumed: totals.protein, goal: user.dailyProteinGoal, defaultColor: .red, unit: "g")
           macroRing(label: "Carbs", consumed: totals.carbs, goal: user.dailyCarbGoal, defaultColor: .blue, unit: "g")
           macroRing(label: "Fat", consumed: totals.fat, goal: user.dailyFatGoal, defaultColor: .yellow, unit: "g")
       }
       ```

    3. **Add helper view builder** `macroRing()` that:
       - Calculates progress percentage: `consumed / goal` (guard against zero goal)
       - Determines color based on progress:
         - Under 85%: defaultColor at 0.7 opacity
         - 85-100%: defaultColor at full opacity (on track)
         - Over 100%: `.red` (over target)
       - Uses CircularProgressRing with size: 70, lineWidth: 6
       - Shows consumed/goal below ring as "X / Y" text
       - Shows remaining text: "X left" or "+X over"

    4. **Add helper functions:**
       - `progressPercentage(consumed:goal:)` - Returns Double 0.0-1.0+
       - `progressColor(for:defaultColor:)` - Returns Color based on thresholds
       - `remainingText(consumed:goal:)` - Returns "X left" or "+X over" String

    5. **Remove old helpers:**
       - Delete `macroProgressRow()` function (lines 83-119)
       - Delete `progressWidth()` function (lines 121-125)

    6. **Update accessibility:**
       - Each ring already has built-in accessibility from CircularProgressRing
       - Add identifier to card: `.accessibilityIdentifier("nutrition-rings-card")`

    **Color coding thresholds:**
    - Under 85%: Softer color (indicates room to consume more)
    - 85-100%: Full color (on track)
    - Over 100%: Red (exceeded target)

    **Layout specifications:**
    - Ring size: 70pt (fits 4 rings in HStack on iPhone SE)
    - Line width: 6pt
    - Spacing: 16pt between rings
    - Below each ring: consumed value, divider line, goal value, remaining text
