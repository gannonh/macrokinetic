**Problem analysis:**
- Current FTS5 uses `ORDER BY rank` which is basic BM25
- Open Food Facts (1.7M entries) dominates results because:
  1. More entries = more matches for any term
  2. Branded products often repeat search term ("Applesauce, apple")
- USDA foundation (287) + sr_legacy (7,793) = 8,080 high-quality whole foods
- Search "apple" returns 20 Open Food Facts items before any USDA apples
- Search "egg" returns "Eggo eggiji" before "Eggs, Grade A, Large, egg whole"

**Solution approach:**
FTS5 supports custom ranking with `bm25()` function and column weights:
```sql
SELECT ... ORDER BY bm25(foods_fts, 10.0, 1.0)  -- weight name 10x, category 1x
```

Additionally, we can boost USDA sources using a CASE expression:
```sql
ORDER BY (CASE WHEN f.source IN ('foundation', 'sr_legacy') THEN 0 ELSE 1 END), bm25(...)
```

This is a pure SQL change - no schema migration needed, just update the query.
