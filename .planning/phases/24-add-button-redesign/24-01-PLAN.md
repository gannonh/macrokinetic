<task type="auto">
  <name>Task 1: Update Add tab item to icon-only with larger icon</name>
  <files>JabTracker/ContentView.swift</files>
  <action>
    Modify the Add tab item (lines 72-76) to use a custom Label that:
    1. Shows empty text (hides the "Add" label)
    2. Uses larger icon font (~28pt, weight: .semibold)
    3. Optionally uses `.symbolRenderingMode(.hierarchical)` for depth

    Change from:
    ```swift
    Color.clear
        .tabItem {
            Label(Tab.add.title, systemImage: Tab.add.icon)
        }
        .tag(Tab.add)
    ```

    To:
    ```swift
    Color.clear
        .tabItem {
            Label {
                Text("")
            } icon: {
                Image(systemName: Tab.add.icon)
                    .font(.system(size: 28, weight: .semibold))
            }
        }
        .tag(Tab.add)
    ```

    Note: Keep the existing `Tab.add.icon` ("plus.circle.fill") - no need to change Tab.swift.
  </action>
  <verify>./scripts/build.sh succeeds without errors</verify>
  <done>Add tab item displays icon-only with larger size, no text label visible</done>
