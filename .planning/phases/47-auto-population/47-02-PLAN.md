Add auto-population call following the exact pattern of ensureTDEESnapshots:

1. Add private method after ensureTDEESnapshots():
```swift
/// Ensure scheduled foods are populated for today and any missed days
/// Runs once per day on app launch, backfilling any missed days
private func ensureScheduledFoodsPopulated() async {
    guard let autoPopService = AppServices.shared.foodAutoPopulationService else {
        logger.debug("FoodAutoPopulationService unavailable, skipping auto-population")
        return
    }

    do {
        try await autoPopService.populateMissedDays()
    } catch {
        logger.error("Food auto-population failed: \(error.localizedDescription)")
    }
}
```

2. Update .task modifier to call the new method after ensureTDEESnapshots():
```swift
.task {
    await ensureTDEESnapshots()
    await ensureScheduledFoodsPopulated()  // NEW
    updateCheckInBadge()
}
```

Order matters: TDEE should run before food population since both access SwiftData.
