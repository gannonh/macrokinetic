  <name>Task 1: Create FoodAutoPopulationService</name>
  <files>JabTracker/Services/FoodAutoPopulationService.swift</files>
  <action>
Create FoodAutoPopulationService following the ContentView.ensureTDEESnapshots pattern:

1. Service structure:
```swift
@MainActor
@Observable
final class FoodAutoPopulationService {
    private static let logger = Logger(...)
    private let context: ModelContext
    private let scheduleService: FoodScheduleService
    private let mealLogService: MealLogService

    private static let lastPopulatedDateKey = "lastFoodAutoPopulationDate"

    init(context: ModelContext, scheduleService: FoodScheduleService, mealLogService: MealLogService)
}
```

2. Main method `populateMissedDays()`:
   - Read last populated date from UserDefaults (default to yesterday if first run)
   - Skip if already populated today
   - Loop from (lastPopulated + 1) through today, calling populateDay() for each
   - Update lastPopulated date on success

3. Private method `populateDay(_ date: Date)`:
   - Call scheduleService.getSchedules(for: date) to get applicable schedules
   - Call mealLogService.getEntries(for: date) to get existing entries
   - Create Set of FoodMealKey (foodId + meal) from existing entries for O(1) lookup
   - For each schedule, for each meal from scheduledMeals(for: date):
     - Skip if FoodMealKey already exists (prevents duplicates)
     - Create FoodEntry using createFoodEntry(from:meal:date:) helper
     - Insert into context
   - Save context

4. Private helper `createFoodEntry(from schedule: FoodSchedule, meal: MealSection, date: Date) -> FoodEntry`:
   - Use FoodEntry's direct initializer (not convenience init from Food)
   - Map all properties from FoodSchedule:
     - foodId, foodName, foodBrand
     - servingGrams, servingDescription, servingOptionsJSON
     - All nutrition per100g values
     - loggedAt = date (start of day)
     - notes = nil

5. Private struct `FoodMealKey: Hashable` for duplicate detection:
   - foodId: UUID
   - meal: MealSection

Use OSLog for logging (info for successful population, debug for skips, error for failures).
