4. Calorie Floor (standard, low)
5. Weekly Distribution (even, shifted)
6. Protein Level (low, moderate, high, extraHigh)
7. Confirmation (review + save)

    - @State var viewModel = GoalWizardViewModel()

    - ProgressView showing progressPercent
    - Switch on currentStep to render step view
    - Handle Continue: if confirmation step, call save() and dismiss
    - .alert for errorMessage display

    - DietPreferenceStep: ForEach(DietPreference.allCases) with macroPercentages preview
    - CalorieFloorStep: ForEach(CalorieFloorType.allCases) with minimumCalories display
    - WeeklyDistributionStep: ForEach(WeeklyDistributionMode.allCases)
    - ProteinLevelStep: ForEach(ProteinLevel.allCases) with gramsPerKg
    - ConfirmationStep: Summary of all selections

    **Selection Card Pattern** (inline private struct):

    - .buttonStyle(.plain), spring animation on selection
    - accessibilityIdentifier: "wizard-step-{step}-{option}"
