# Phase 13 Plan 2: Goal/Program Design Refactor

**Separate Goal and Program into distinct wizards with correct domain boundaries**

## Context

Design review of mocks (`mocks/goal-program/`) revealed that the 13-01 implementation conflates Goal and Program concepts. The correct design separates them:

### Design Summary

**Strategy Screen** (IMG_2012):
- New view with "New Goal", "Edit Goal", "New Program" buttons
- Countdown ring showing days until check-in
- Current program display with daily macro targets

**Correct Domain Separation**:

| Goal | Program |
|------|---------|
| Goal Type (Lose/Maintain/Gain) | Program Style (Coached/Collaborative/Manual) |
| Target Weight (e.g., 180 lbs) | Diet Preference |
| Rate of Change (e.g., 1.5 lbs/week) | Calorie Floor |
| | Training (None or Relaxed) |
| | Weekly Distribution |
| | Protein Level |

**Flow Logic**:
1. **New Goal** → Goal wizard → chains to **New Program** wizard (2-step intro)
2. **Edit Goal** → Goal wizard → Program summary screen with "Looks Good" or "Set New Program"
3. **New Program** → Full program wizard starting at Program Style selection
4. **Edit Program** → Edit current program type's settings (skips style, starts at Diet Preference)

### Current Implementation Issues

The 13-01 `GoalConfigurationWizard` conflates Goal and Program:
- GoalType is in the wizard but should be **Goal Step 1**
- Missing: Target Weight, Rate of Change input
- Missing: Separate edit paths for Goal vs Program
- Entry point is wrong (should be "Strategy" view, not More menu)

## Tasks

### Task 1: Update NutritionGoal Model

**Goal**: Add target weight and rate of change fields to NutritionGoal

**TDD approach**:
1. Write failing tests for new properties
2. Add properties to NutritionGoal model:
   - `targetWeightKg: Double` - Target weight in kilograms
   - `weeklyRateKg: Double` - Weekly rate of change (negative for loss, positive for gain)
   - `startWeightKg: Double` - Starting weight when goal was created
   - `startDate: Date` - When goal was created (for projected end date calculation)
3. Add computed properties:
   - `projectedEndDate: Date?` - Calculated from current weight, target, and rate
   - `initialDailyBudget: Int?` - Estimated daily calorie budget

**Files**:
- `JabTracker/Models/NutritionGoal.swift`
- `JabTrackerTests/Models/NutritionGoalTests.swift`

### Task 2: Create GoalWizard (Separate from Program)

**Goal**: Create a standalone Goal wizard with 3 steps

**Steps**:
1. Goal Type selection (Lose Weight / Maintain Weight / Gain Weight)
2. Target weight and rate configuration (with sliders, shows calculated budget/end date)
3. Goal summary confirmation

**Implementation**:
- Create `GoalWizard.swift` with `GoalWizardViewModel`
- Intro screen with rocket illustration showing 2-step process
- Step views for goal type, weight/rate config, summary
- On completion: Creates NutritionGoal, chains to ProgramWizard

**Files**:
- `JabTracker/Views/Nutrition/GoalWizard.swift` (NEW)

### Task 3: Refactor ProgramWizard (Remove GoalType)

**Goal**: Refactor current wizard to be Program-only

**Changes**:
1. Rename `GoalConfigurationWizard` → `ProgramWizard`
2. Remove GoalType step (now part of Goal wizard)
3. Update ViewModel to work with existing NutritionGoal
4. Add Training step (None or Relaxed) - new enum needed
5. Steps: Program Style → Diet Preference → Calorie Floor → Training → Weekly Distribution → Protein Level → Confirmation
6. Support "edit mode" that skips Program Style (for Edit Program flow)

**Files**:
- `JabTracker/Views/Nutrition/GoalConfigurationWizard.swift` → `ProgramWizard.swift`
- `JabTracker/Models/ProgramConfiguration.swift` - Add `TrainingLevel` enum
- Update E2E test stubs

### Task 4: Create Strategy View with Entry Points

**Goal**: Create the Strategy tab/view shown in mocks

**Implementation**:
- Create `StrategyView.swift` as main view
- Action buttons: "New Goal", "Edit Goal", "Edit Program", "New Program"
- Countdown ring showing days until next check-in
- "In Progress" section showing current program with daily targets
- Goal/Check-In toggle (for later phases)

**Entry point logic**:
- "New Goal" → GoalWizard → chains to ProgramWizard (full 2-step flow)
- "Edit Goal" → GoalWizard → ProgramSummarySheet ("Looks Good" or "Set New Program")
- "Edit Program" → ProgramWizard in edit mode (skips style, title: "Edit {Style} Program")
- "New Program" → ProgramWizard full flow (starts at Program Style)

**ProgramSummarySheet** (shown after Edit Goal):
- Displays current program settings as grid cards
- Two actions: "Looks Good" (dismiss) or "Set New Program" (launch ProgramWizard)

**Files**:
- `JabTracker/Views/Strategy/StrategyView.swift` (NEW)
- `JabTracker/Views/Strategy/ProgramSummarySheet.swift` (NEW)
- Update `ContentView.swift` or `MoreView.swift` for navigation
