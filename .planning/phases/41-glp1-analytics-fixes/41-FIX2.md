<task type="auto">
  <name>Task 1: Fix histogram to show discrete bars with gaps like Google Popular Times</name>
  <files>JabTracker/Views/Analytics/ConcentrationTimelineChart.swift, JabTracker/Models/ChartData.swift, JabTracker/Services/ChartDataProcessor.swift</files>
  <action>
**Root Cause:** BarMark is used but with 0.5-hour intervals = 1440 bars that blend together with no visible gaps.

**Issue:** Chart displays as area/line chart with fill, not discrete histogram bars like Google Popular Times

**Expected:** Discrete, separated bars with rounded tops and visible gaps between them

**Fix:**

1. **Scale intervalHours based on time range** in ChartData.swift and ChartDataProcessor.swift:
   - 7d view: 2-hour intervals (~84 bars)
   - 30d view: 6-hour intervals (~120 bars)
   - 90d view: 12-hour intervals (~180 bars)
   - 1y view: 24-hour intervals (~365 bars)

   Create a helper function or modify InterpolationSettings to accept time range and return appropriate interval.

2. **Add explicit bar width with gaps** in ConcentrationTimelineChart.swift:
   - Use BarMark with explicit width: `.width(ratio: 0.7)` to create 30% gaps between bars
   - This creates visible separation between bars

3. **Add cornerRadius for rounded tops** in ConcentrationTimelineChart.swift:
   - Add `.clipShape(RoundedRectangle(cornerRadius: 4))` or use `.cornerRadius(4)` on BarMark
   - This creates the rounded pill appearance like Google Popular Times

Example BarMark update:
```swift
BarMark(
    x: .value("Time", point.date),
    y: .value("Concentration", point.concentration),
    width: .ratio(0.7)
)
.foregroundStyle(DesignTokens.Colors.primary.opacity(0.8))
.clipShape(RoundedRectangle(cornerRadius: 4))
```

**Important:** The key insight is that we need FEWER bars with GAPS, not more bars packed together.
