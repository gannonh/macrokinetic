**Root Cause:** BarMark is used but with 0.5-hour intervals = 1440 bars that blend together into what looks like an area fill.

**Issue:** Chart displays as area/line chart with fill, not vertical histogram bars

**Expected:** Visible vertical bars showing concentration (y-axis) over time (x-axis)

**Fix:**

**Scale intervalHours based on time range** in ChartData.swift and ChartDataProcessor.swift:
   - 7d view: 2-hour intervals (~84 bars)
   - 30d view: 6-hour intervals (~120 bars)
   - 90d view: 12-hour intervals (~180 bars)
   - 1y view: 24-hour intervals (~365 bars)

The key insight: fewer bars = each bar is wider and individually visible. Bars can touch each other (no gaps needed), just need to be distinguishable as vertical bars.

Create a helper function or modify InterpolationSettings to accept time range and return appropriate interval. The BarMark itself doesn't need changes - Swift Charts will automatically make bars wider when there are fewer data points.
