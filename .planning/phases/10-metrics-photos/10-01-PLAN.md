  <action>
    Create SwiftData model for progress photos:

    **PhotoType enum (define at top of file):**
    ```swift
    enum PhotoType: String, CaseIterable, Identifiable, Codable {
        case front = "front"
        case side = "side"
        case back = "back"

        var id: String { rawValue }
        var displayName: String {
            switch self {
            case .front: return "Front"
            case .side: return "Side"
            case .back: return "Back"
            }
        }
        var icon: String {
            switch self {
            case .front: return "person.fill"
            case .side: return "person.crop.rectangle"
            case .back: return "person.fill.turn.right"
            }
        }
    }
    ```

    - `notes: String?`

    **Computed properties:**
    - `photoTypeEnum: PhotoType` - get/set wrapper for photoType string
    - `hasValidPhoto: Bool` - imageData != nil && imageData!.count > 0
