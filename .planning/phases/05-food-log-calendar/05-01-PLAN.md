    ```swift

            entriesGroupedByDate: entriesGroupedByDate

        .listRowBackground(Color.clear)
    }
    ```

    **Update daily summary title:**
    - Replace hardcoded "Today" with computed property
    - Show "Today" if selectedDate is today

    **Add week data loading:**
    - Add `.task(id: selectedDate)` modifier to trigger loadWeekEntries()
    - Create loadWeekEntries() async method that:
      - Gets week interval from selectedDate
      - Loops 7 days, calls mealLogService.getEntries(for:) each
      - Stores counts in entriesGroupedByDate dictionary
      - Uses calendar.startOfDay(for:) as dictionary keys

    **Avoid:**
