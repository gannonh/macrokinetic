  <action>
Create FoodScheduleService.swift following the CustomFoodService pattern:

**FoodScheduleError enum** (LocalizedError, Equatable):
- invalidConfiguration: "Schedule configuration is invalid"
- foodNotFound: "Food not found"

**FoodScheduleService class** (@MainActor):
- Private logger: Logger(subsystem: "com.gannonhall.JabTracker", category: "FoodScheduleService")
- Dependencies: context (ModelContext), customFoodService (CustomFoodService)
- Init with context and customFoodService

**CRUD Methods:**

1. `createOrUpdateSchedule(for food: Food, config: ScheduleConfig, servingGrams: Double, servingDescription: String, startDate: Date?, endDate: Date?) async throws -> FoodSchedule`:
   - Validate config.isValid, throw .invalidConfiguration if not
   - If food.isCustomFood is false, convert to custom via customFoodService.createCustomFood (SCHED-04)
   - Fetch existing schedule for foodId (one-per-food constraint, SCHED-07)
   - If exists: update and return existing
   - If not: create new FoodSchedule, insert, save, return
   - Log operations with logger.info

2. `getSchedule(for foodId: UUID) async throws -> FoodSchedule?`:
   - FetchDescriptor with predicate: schedule.foodId == foodId
   - Return first result or nil

3. `getAllActiveSchedules() async throws -> [FoodSchedule]`:
   - FetchDescriptor with predicate: schedule.isActive == true
   - Sort by foodName
   - Return results

4. `getSchedules(for date: Date) async throws -> [FoodSchedule]`:
   - Get all active schedules
   - Filter by schedule.appliesTo(date: date)
   - Return filtered results

5. `updateSchedule(_ schedule: FoodSchedule, config: ScheduleConfig, servingGrams: Double, servingDescription: String, startDate: Date?, endDate: Date?) async throws -> FoodSchedule`:
   - Validate config.isValid
   - Update all fields, set updatedAt
   - Save context
   - Log and return

6. `deleteSchedule(_ schedule: FoodSchedule) async throws`:
   - Log food name
   - Delete from context
   - Save

**Private helper:**
- `convertToCustomFood(_ food: Food) async throws -> Food`:
   - Create CustomFoodInput from food properties (empty barcode to avoid conflicts)
   - Call customFoodService.createCustomFood
   - Log conversion
   - Return new custom food
  </action>
