  <files>

  </files>
  <action>
Create FoodSchedule.swift as a SwiftData @Model (follow FoodEntry pattern):

**Properties (all non-optional with defaults for CloudKit):**
- id: UUID (default UUID())
- foodId: UUID (reference to custom Food, default UUID())
- foodName: String (denormalized, default "")
- foodBrand: String (denormalized, default "")
- scheduleConfigData: Data (JSON-encoded ScheduleConfig, default Data())
- servingGrams: Double (default 100.0)
- servingDescription: String (default "")
- servingOptionsJSON: String (default "[]")
- caloriesPer100g, proteinPer100g, carbsPer100g, fatPer100g, fiberPer100g: Double (all default 0.0)
- startDate: Date? (optional start)
- endDate: Date? (optional end)
- isActive: Bool (default true)
- createdAt: Date (default Date())
- updatedAt: Date (default Date())

**Computed property scheduleConfig:**
- Getter: decode scheduleConfigData to ScheduleConfig (return nil if empty/invalid)
- Setter: encode to scheduleConfigData, update updatedAt

**Methods:**
- appliesTo(date: Date) -> Bool: Check isActive, startDate, endDate
- scheduledMeals(for date: Date) -> [MealSection]: Get meals if date applies and matches day of week

**Init:** Accept all required parameters with sensible defaults

Create FoodScheduleTests.swift with tests:
- Model initializes with default values
- scheduleConfig computed property encodes/decodes correctly
- appliesTo returns false when isActive is false
- appliesTo respects startDate (returns false if date before start)
- appliesTo respects endDate (returns false if date after end)
- appliesTo returns true when date is within range
- scheduledMeals returns correct meals for matching day of week
- scheduledMeals returns empty array when date doesn't match any scheduled day
- updatedAt is set when scheduleConfig changes
  </action>

Run `./scripts/test.sh unit 1 FoodScheduleTests` - all tests pass
  </verify>
