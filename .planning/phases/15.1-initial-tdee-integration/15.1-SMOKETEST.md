Manual Testing Instructions - Phase 15.1

  Prerequisites

  - Run on a physical device or simulator with HealthKit support
  - Have the Health app accessible

  ---
  1. Account View Structure

  1. Open app → More tab → Account
  2. Verify sections appear:
    - Profile header (avatar, name, email)
    - Details section (Name, Birthday, Sex, Height, Weight, Cardio Experience, Lifting Experience)
    - Security section (Face ID/Touch ID toggle) - only if available
    - Integrations section (Health toggle with heart icon)
    - Account actions (Log Out, Restart Onboarding)

  ---
  2. Health Sync - Enable Flow

  1. Reset simulator (to clear cached HealthKit permissions)
  2. Ensure Health toggle is OFF
  3. Tap Health toggle to enable
  4. Verify: iOS HealthKit permission prompt appears with ALL types:
     - Write: Body Fat Percentage, Height, Waist Circumference, Weight
     - Read: Same 4 + Biological Sex, Date of Birth
  5. Tap "Turn On All" and Allow
  6. Verify: Toggle switches to ON
  7. Verify: In Health app → Sharing → MacroKinetic shows permissions granted

  ---
  3. Health Sync - Disable Flow

  1. Ensure Health toggle is ON
  2. Tap Health toggle to disable
  3. Verify confirmation dialog appears with:
    - Title: "Disable Health Sync"
    - Message mentioning Apple Health and how to revoke permissions
    - "Disable" button (destructive)
    - "Cancel" button
  4. Tap Cancel → Toggle stays ON
  5. Tap toggle again → Tap Disable
  6. Verify: Toggle switches to OFF

  ---
  4. Weight Logging (Profile)

  1. Enable Health sync (toggle ON)
  2. Go to Account → tap Weight row
  3. Change weight value
  4. Tap Save
  5. Verify in app: Weight displays new value
  6. Verify in Health app: Body Measurements → Weight shows new entry with timestamp

  ---
  5. Weight Logging (Quick Add)

  1. Enable Health sync
  2. Tap "+" tab → Log Weight
  3. Enter a weight value
  4. Tap Save
  5. Verify: Sheet dismisses
  6. Verify in Health app: New weight entry appears

  ---
  6. Height Editing

  1. Enable Health sync
  2. Go to Account → tap Height row
  3. Verify: Wheel pickers for feet/inches (no "Get from Health" button)
  4. Change height using pickers
  5. Tap Save
  6. Verify in app: Height displays new value
  7. Verify in Health app: Body Measurements → Height shows new entry

  ---
  7. Bidirectional Sync - Read CURRENT Value from HealthKit

  Note: We read CURRENT values from HealthKit, not history. Historical data
  for TDEE comes from tracking in our app.

  1. Enable Health sync in app
  2. In Health app: Manually add a weight entry (different from current)
  3. Return to app → Account
  4. Verify: Weight row shows the value from Health app (HealthKit is source of truth)
  5. Repeat for Height: Add height in Health app, verify app shows it

  ---
  8. Health Sync Disabled - Local Only

  1. Disable Health sync (confirm dialog)
  2. Go to Account → Change weight
  3. Verify: Weight saves locally (no HealthKit prompt)
  4. Verify in Health app: No new entry created

  ---
  9. Profile Field Editing

  Test each editable field in Account → Details:
  - Name: Edit, save, verify persisted
  - Birthday: Date picker works, save, verify
  - Sex: Picker with Male/Female/Not set, save, verify
  - Height: Wheel pickers (ft/in), save, verify
  - Weight: Stepper, save, verify
  - Cardio Experience: Beginner/Intermediate/Advanced, save, verify
  - Lifting Experience: Beginner/Intermediate/Advanced, save, verify

  ---
  10. Security - Biometric Toggle

  (If device supports Face ID/Touch ID)
  1. Toggle Face ID/Touch ID on
  2. Verify: Biometric prompt appears
  3. Toggle off
  4. Verify: Setting persists

  ---
  11. Account Actions

  1. Test Log Out:
    - Tap "Log Out" → Confirmation dialog appears
    - Cancel → Nothing happens
    - Confirm → Logs out (if auth enabled)
  2. Test Restart Onboarding:
    - Tap "Restart Onboarding" → Confirmation dialog appears
    - Cancel → Nothing happens
    - Confirm → Resets onboarding state

  ---
  12. Onboarding - HealthKit Permissions

  1. Reset simulator and app data
  2. Go through onboarding to HealthKit step
  3. Verify: Same permission prompt as Account toggle (all 6 types)
  4. Grant permissions
  5. Complete onboarding
  6. Verify: Health toggle in Account is ON

  ---
  13. Edge Cases

  - No HealthKit access: Deny permission → Error message appears, toggle stays OFF
  - Weight with body fat: In Quick Weight sheet, add body fat % → Verify syncs to Health
  - Different weight units: Change between kg/lbs, verify conversions correct
  - Waist sync: Log waist measurement → Verify appears in Health app
