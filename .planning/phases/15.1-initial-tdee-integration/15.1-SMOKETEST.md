   - Step 1: "Estimated Expenditure (TDEE)" with calculated value (e.g., "2200 kcal")
   - Step 2: "Daily Target" with deficit/surplus applied (e.g., "1850 kcal")
   - Step 3: "Macro Split" with diet name and P/F/C breakdown

### 15. TDEE Calculation Accuracy

**Test Profile (exact values):**
- Sex: Male
- Weight: 180 lbs (81.6 kg)
- Height: 5'10" (178 cm)
- Birthday: Dec 29, 1995 (age 29-30)
- Training Level: Lifting (or Cardio) — both use 1.55 multiplier

**Goal Wizard Settings:**
- Goal Type: Weight Loss
- Target Weight: 170 lbs (77.1 kg) — lose 10 lbs
- Weekly Rate: 1.0 lbs/week

**Expected Calculations (Mifflin-St Jeor):**
```
BMR = (10 × 81.6) + (6.25 × 178) - (5 × 30) + 5
BMR = 816 + 1112.5 - 150 + 5 = 1783 kcal

TDEE = BMR × 1.55 (moderate activity)
TDEE = 1783 × 1.55 ≈ 2764 kcal

Weekly deficit for 1 lb/week = 3500 kcal
Daily deficit = 500 kcal

Daily Target = 2764 - 500 = 2264 kcal
```

**Program Wizard Settings:**
- Program Style: Coached
- Diet Preference: Balanced (30% P / 40% C / 30% F)

**Expected Macro Breakdown (at ~2264 kcal):**
```
Protein: 2264 × 0.30 = 679 kcal ÷ 4 = 170g
Carbs:   2264 × 0.40 = 906 kcal ÷ 4 = 226g
Fat:     2264 × 0.30 = 679 kcal ÷ 9 = 75g
```

**Expected Program Ready Sheet Values:**
- Step 1 TDEE: ~2750-2800 kcal
- Step 2 Daily Target: ~2250-2300 kcal
- Step 3 Macros (Balanced): ~170g P / ~226g C / ~75g F
- Duration: 10 weeks

**Verification Steps:**
1. Set profile to exact values above
2. Create Goal: Weight Loss, Target 170 lbs, Rate 1.0 lbs/week
3. Select Coached program with Balanced diet
4. On Program Ready Sheet, verify:
   - TDEE shows approximately 2750-2800 kcal
   - Daily target shows approximately 2250-2300 kcal
   - Macros show approximately 170g P / 226g C / 75g F
   - Weekly grid shows same values for all 7 days
   - Values are within ±5% of expected calculations

### 18. HealthKit Biometrics for TDEE (MetricsService Abstraction)

**Critical: TDEE must use HealthKit data when sync is enabled**

1. Enable Health sync in Account
2. In Health app: Set weight to 200 lbs (different from app's local value)
3. In Health app: Set height to 6'0" (different from local)
4. Create new Coached program
5. Verify: TDEE calculation uses HealthKit values:
   - Program Ready Sheet should show TDEE based on 200 lbs, 6'0"
   - Not the stale local data
6. Disable Health sync
7. Create another Coached program
8. Verify: Now uses local profile values (not HealthKit)

**Technical Note:** TDEEService uses MetricsService for ALL biometric reads:
- `getCurrentWeight(for:)` → HealthKit if sync enabled, else local
- `getCurrentHeight(for:)` → HealthKit if sync enabled, else local
- `getCurrentGender(for:)` → HealthKit if sync enabled, else local
- `getCurrentDateOfBirth(for:)` → HealthKit if sync enabled, else local

### 21. Calorie Deficit/Surplus Calculation Accuracy

**Critical: Daily target = TDEE ± (weeklyPaceKg × 1100)**

**Test Case: 1 lb/week weight loss**
1. Set profile: Male, 180 lbs, 5'10", age 30, Lifting
2. Create goal: Weight Loss, 1.0 lbs/week
3. Verify on Program Ready Sheet:
   - TDEE: ~2700 kcal
   - Daily Target: ~2200 kcal (TDEE - 500)
   - Deficit should be ~500 kcal (1 lb/week = 3500 kcal/week ÷ 7 = 500/day)

**Test Case: 0.5 lbs/week weight loss**
1. Same profile
2. Create goal: Weight Loss, 0.5 lbs/week
3. Verify: Daily Target = TDEE - 250 kcal

**Test Case: 1 lb/week weight gain**
1. Same profile
2. Create goal: Weight Gain, 1.0 lbs/week
3. Verify: Daily Target = TDEE + 500 kcal

**Bug Regression Check:**
- Previous bug divided by 7 twice, showing ~2630 instead of ~2200
- If Daily Target is suspiciously close to TDEE for aggressive goals, calculation is wrong
