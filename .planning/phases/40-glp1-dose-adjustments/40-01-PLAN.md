<objective>
Allow users to adjust dose amount when logging GLP-1 doses, supporting compounded medication titration.

Purpose: Currently, dose amount is displayed as read-only in the Quick Add Dose sheet, forcing users with compounded medications to either edit their profile or log inaccurate doses. This change enables per-dose adjustments while keeping the profile as the default.

Output: Editable dose amount control in QuickDoseEntrySheet with medication-appropriate constraints.
</objective>

  <name>Task 1: Make dose amount editable in QuickDoseEntrySheet</name>
  <files>JabTracker/Views/DoseEntry/QuickDoseEntry.swift, JabTracker/ViewModels/QuickDoseViewModel.swift</files>
  <action>
Replace the static dose amount display with an interactive Stepper control:

1. In `QuickDoseEntrySheet`, replace the static HStack showing dose amount (around line 155-161) with a Stepper:
   ```swift
   Stepper(
       value: $viewModel.doseAmount,
       in: viewModel.doseAmountRange,
       step: viewModel.doseAmountStep
   ) {
       HStack {
           Text("Dose Amount")
           Spacer()
           Text("\(viewModel.doseAmount, specifier: "%.2f") mg")
               .foregroundColor(.secondary)
       }
   }
   .accessibilityIdentifier("quick-dose-entry-amount-stepper")
   ```

2. In `QuickDoseViewModel`, add computed properties for dose constraints:
   - `doseAmountRange: ClosedRange<Double>` - min/max based on medication type
   - `doseAmountStep: Double` - increment based on whether compounded (0.25mg) or branded (fixed doses)
   - For compounded ("Generic" brand): Allow 0.25mg steps from min to max of medication type
   - For branded: Use `Medication.availableDoses(for: brand)` to constrain to valid pen doses

3. Update `updateDoseAmount()` to set initial dose from profile but allow user adjustment within constraints.

4. Consider edge case: If user adjusts dose, then changes medication selection, reset to new profile's default dose.

Do NOT:
- Offer to update the profile dose from the logged dose (keep profile and logged dose separate)
- Use a TextField (Stepper is more discoverable and prevents invalid input)
- Allow doses outside medication's therapeutic range
