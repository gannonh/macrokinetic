  <name>Task 2: Create USPShowcaseStepView with carousel</name>
  <files>JabTracker/Onboarding/Views/USPShowcaseStepView.swift</files>
  <action>
    Create a carousel view showcasing 4 key features:

    **Data model (inline struct):**
    ```swift
    private struct USPFeature: Identifiable {
        let id = UUID()
        let icon: String           // SF Symbol name
        let title: String
        let description: String
    }
    ```

    **Features to display:**
    1. Adaptive TDEE - icon: "chart.line.uptrend.xyaxis" - "Your metabolism adapts. So does MacroKinetic." - "Learn your body's true calorie needs as you progress."
    2. Precision Tracking - icon: "barcode.viewfinder" - "Track every macro with confidence" - "1.7M+ foods, barcode scanning, custom foods."
    3. Calorie Adjustments - icon: "flame.fill" - "Smart adjustments for real results" - "Activity-based recommendations that evolve with you."
    4. GLP-1 Support - icon: "syringe.fill" - "Made for your medication journey" - "Optional GLP-1 tracking with dose reminders."

    **Layout:**
    - TabView with .tabViewStyle(.page(indexDisplayMode: .never))
    - ForEach over features array
    - Each page: Large icon (64-80pt), title (headline), description (body)
    - Custom page indicators below TabView (12pt circles, primary color for selected)
    - Use @State var currentPage: Int = 0 for tracking

    **Implementation:**
    - Create struct `USPShowcaseStepView: View`
    - Private static let features array with 4 USPFeature items
    - Use DesignTokens.Colors.primaryGradient for icons
    - Use DesignTokens.Colors.primary for selected page dot
    - Add `.accessibilityElement(children: .combine)` to each feature card
    - Add `.accessibilityIdentifier("onboarding-usp-showcase-step")` to root
    - Add `.accessibilityIdentifier("usp-feature-\(index)")` to each card

    **Reference WelcomeScreensView pattern for carousel:**
    - Same TabView + PageTabViewStyle approach
    - Same custom HStack page dots pattern
    - Optional: Animation on page change

    **DO NOT:**
    - Add auto-advance timer (let user control pace)
    - Add Skip button (handled by OnboardingView navigation)
  </action>
  <verify>xcodegen generate && ./scripts/build.sh</verify>
  <done>USPShowcaseStepView.swift exists, builds without errors, SwiftUI preview shows carousel with 4 features</done>

<task type="auto">
  <name>Task 3: Update OnboardingView routing</name>
  <files>JabTracker/Onboarding/OnboardingView.swift</files>
  <action>
    Update the stepContent() function to route to new views:

    **Current code (line ~123-125):**
    ```swift
    @ViewBuilder
    private func stepContent(for step: OnboardingStep, viewModel: OnboardingViewModel) -> some View {
        PlaceholderStepView(step: step)
    }
    ```

    **Updated code:**
    ```swift
    @ViewBuilder
    private func stepContent(for step: OnboardingStep, viewModel: OnboardingViewModel) -> some View {
        switch step {
        case .welcome:
            WelcomeStepView()
        case .uspShowcase:
            USPShowcaseStepView()
        default:
            PlaceholderStepView(step: step)
        }
    }
    ```

    This keeps PlaceholderStepView as fallback for steps not yet implemented (Phases 27-29).

    **DO NOT:**
    - Pass viewModel to WelcomeStepView or USPShowcaseStepView (they're pure presentation)
    - Remove PlaceholderStepView (still needed for other steps)
    - Change navigation button logic
  </action>
  <verify>xcodegen generate && ./scripts/build.sh</verify>
  <done>OnboardingView.swift routes .welcome and .uspShowcase to new views, other steps still use placeholder, build succeeds</done>
</task>
