# Smoke Test: Per-Day Macro UI (15.2-03)

## Feature
Per-day macro display in ProgramReadySheet, Dashboard, and Food Log. Shows different calorie/macro targets for different days based on program configuration (Coached/Shifted, Collaborative, Manual).

## How to Test

### Test 1: Coached/Shifted Mode
1. Navigate to Strategy tab
2. Start a new Coached program wizard
3. Complete diet preference, calorie floor, training level steps
4. On distribution step, select "Shift Calories"
5. Select 3 high-calorie days (e.g., Mon, Wed, Fri)
6. Complete protein level and confirmation steps
7. **Verify**: ProgramReadySheet shows different calorie values for high days (~1468) vs low days (~1398)

### Test 2: Collaborative Mode
1. Navigate to Strategy tab
2. Start a new program wizard
3. Select "Collaborative" style
4. Complete training level and distribution steps
5. On macro customization step, adjust protein g/lb slider and carb/fat ratio slider
6. Complete confirmation step
7. **Verify**: ProgramReadySheet shows calculated macros based on slider values

### Test 3: Manual Mode - Same All Week
1. Navigate to Strategy tab
2. Start a new program wizard
3. Select "Manual" style
4. Select "Same All Week" target mode
5. Enter single set of macro targets (e.g., 2000 cal, 150P, 65F, 200C)
6. Complete confirmation step
7. **Verify**: ProgramReadySheet shows same values for all 7 days

### Test 4: Manual Mode - Different Per Day
1. Navigate to Strategy tab
2. Start a new program wizard
3. Select "Manual" style
4. Select "Different Per Day" target mode
5. Enter different values for each day (e.g., higher on Mon/Wed/Fri)
6. Complete confirmation step
7. **Verify**: ProgramReadySheet shows different values matching your entries

### Test 5: Food Log Per-Day Targets
1. Create a program with per-day variation (Shifted or Manual per-day)
2. Navigate to Food Log tab
3. Verify daily summary card shows targets
4. Tap different days in week calendar
5. **Verify**: Targets update based on selected day's configuration

### Test 6: Dashboard Per-Day Targets
1. With active program, navigate to Dashboard
2. **Verify**: NutritionSummaryCard shows today's targets from active goal
3. **Verify**: Targets match what Food Log shows for same day

## Expected Behavior
- Coached/Shifted: High days show ~10% more calories than low days
- Collaborative: Macros calculated from protein g/lb and carb/fat ratio
- Manual Same: All 7 days show identical values
- Manual Per-Day: Each day shows the exact values entered
- Food Log: Summary updates when changing selected date
- Dashboard: Shows correct targets for today

## Verification

### Wizard Navigation
- [ ] Coached shows: diet, calorie floor, training, distribution, shifted days (if shifted), protein, confirmation
- [ ] Collaborative shows: training, distribution, macro customization, confirmation
- [ ] Manual shows: target mode, single macros OR per-day macros, confirmation

### ProgramReadySheet Display
- [ ] Coached/Shifted shows per-day calorie variation
- [ ] Collaborative shows calculated macros from sliders
- [ ] Manual Same shows identical values all days
