## What Was Built

### Task 1: TDEESnapshot Model ✅
- Created `TDEESnapshot.swift` SwiftData model following WeightEntry pattern
- Properties: id, timestamp, tdeeValue, confidence, source, createdAt
- Computed properties:
  - `sourceType` - type-safe enum accessor
  - `status` - returns `.holding` / `.updating` / `.fluxRange` based on recency
  - `fluxMargin` - returns margin of error based on confidence (10-50 range)
- Created `TDEESourceType` enum with `.initial`, `.adaptive`, `.manual` cases
- Full TDD implementation with 9 tests

### Task 2: TDEEService Snapshot Methods ✅
- Added `saveTDEESnapshot(tdee:confidence:source:)` method to TDEEService
- Added `getTDEESnapshots(from:to:)` query method for date range fetching
- Updated `calculateInitialTDEE()` to save snapshot with `.initial` source
- Updated `updateGoalWithAdaptiveTDEE()` to save snapshot with `.adaptive` source
- Full TDD implementation with 8 tests

### Task 3: ExpenditureDetailViewModel Live Data ✅
- Added TDEEService dependency
- Replaced `generateDailyData()` synthetic generation with `loadDailyData()` real queries
- Maps TDEESnapshot to DailyExpenditure using snapshot's computed properties
- Graceful fallback to current TDEE when no history exists
- Error handling with fallback for query failures
