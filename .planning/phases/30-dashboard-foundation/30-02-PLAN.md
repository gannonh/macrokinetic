  <action>
    Create the Weekly Nutrition hero widget based on the Figma mock.

    **Layout structure (7-day macro grid):**
    ```
    ┌─────────────────────────────────────────────────────┐
    │ Weekly Nutrition                            (title) │
    │                                                     │
    │ [Day grid: M T W T F S S]                          │
    │ Calories: █▌ █▌ █▌ █▌ █▌ ░░ ░░    1200🔥 of 1395   │
    │ Protein:  █▌ █▌ █▌ █▌ █▌ ░░ ░░      95P of 113    │
    │ Fat:      █▌ █▌ █▌ █▌ █▌ ░░ ░░      40F of 49     │
    │ Carbs:    █▌ █▌ █▌ █▌ █▌ ░░ ░░     110C of 125    │
    │                                                     │
    │      [ Consumed | Remaining ]                       │
    └─────────────────────────────────────────────────────┘
    ```

    **Components to build:**

    1. **HeroToggle** - Generic pill-style toggle (reusable for all hero widgets)
       - Two options: Consumed / Remaining
       - Pill-shaped with white selected state, dark background
       - Create enum `HeroDisplayMode` with `.consumed` and `.remaining` cases

    2. **WeeklyMacroRow** - Row of 7 day cells for one macro
       - Each cell: colored vertical bar showing progress
       - Today's column highlighted with border
       - Use simple RoundedRectangle for bars

    3. **WeeklyNutritionHeroWidget** - Main widget
       - Conforms to DashboardWidget protocol
       - Title: "Weekly Nutrition"
       - VStack: grid rows, summary column, toggle
       - @State for displayMode (consumed/remaining)

    **Mock data (hardcoded for now):**
    - 7 days of sample macro values
    - Targets: Calories 1395, Protein 113g, Fat 49g, Carbs 125g
    - Today = current weekday, partial fill
    - Past days = varied fill levels (60-100%)
    - Future days = empty

    **Macro colors (use simple colors for mock):**
    - Calories: .blue
    - Protein: .orange
    - Fat: .yellow
    - Carbs: .green

    **Toggle behavior:**
    - Consumed: bars show amount eaten
    - Remaining: bars show amount left to target

    **Accessibility:**
    - Widget identifier: "weekly-nutrition-hero-widget"
    - Toggle accessible with both options labeled
