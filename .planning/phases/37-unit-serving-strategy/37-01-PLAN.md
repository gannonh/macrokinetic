Create a new SwiftUI view `ServingPillPicker` that displays serving options as horizontal scrollable pill buttons.

**Structure:**
```swift
struct ServingPillPicker: View {
    let servingOptions: [ServingOption]  // From food.servingOptions
    let defaultServing: ServingOption    // From food.defaultServing
    @Binding var selectedOption: ServingOption
    
    // Always include g and oz as universal fallbacks
    private var allOptions: [ServingOption] { ... }
}
```

**Pills to show (in order):**
1. Default serving pill (e.g., "1 egg • 50g") - if food has item serving
2. All serving options from database that aren't just "100g"
3. "g" pill (always)
4. "oz" pill (always)

**Styling:**
- Horizontal ScrollView with .horizontal, showsIndicators: false
- Each pill: rounded capsule, ~12pt padding, secondary background
- Selected pill: primary color background with contrasting text
- Pill format for items: "1 egg • 50g" or just "100g" for gram options

**Avoid:** Don't include "lb" or "item" generically - only show actual serving options from the data. The item-based servings come from ServingOption, not ServingUnit.
