  <files>JabTracker/Views/Dashboard/Widgets/EnergyBalanceHeroWidget.swift</files>
  <action>
    Create hero widget following established patterns:

    1. **Widget Structure** (DashboardWidget protocol):
       - `id = "energy-balance"`
       - `title = "Energy Balance"`

    2. **Display Mode - Energy Balance specific:**
       - This widget uses different toggle options: Expenditure vs Targets
       - Create local `EnergyDisplayMode` enum: `.expenditure`, `.targets`
       - Use @State for local toggle (NOT shared HeroDisplayMode - this is different)
       - Toggle changes the reference line and comparison value

    3. **Layout (match Figma):**
       - Title "Energy Balance" (15pt semibold)
       - Swift Charts bar chart (~120pt height)
       - "Last 30 Days" caption below chart (right-aligned, 10pt secondary)
       - Summary row below: "815 - 1893 = -1078" with icons/labels
       - Expenditure/Targets segment control at bottom

    4. **Bar Chart Implementation (Swift Charts):**
       ```swift
       import Charts

       Chart {
           // Blue bars for daily calories
           ForEach(mockData.dailyCalories) { day in
               BarMark(
                   x: .value("Day", day.date, unit: .day),
                   y: .value("Calories", day.value)
               )
               .foregroundStyle(DesignTokens.Colors.calories)
           }

           // Reference line (dotted) for expenditure/target
           RuleMark(y: .value("Reference", referenceValue))
               .lineStyle(StrokeStyle(lineWidth: 1, dash: [4, 3]))
               .foregroundStyle(Color.orange)
       }
       .chartXAxis(.hidden)  // Compact view, no axis labels
       .chartYAxis(.hidden)
       .frame(height: 120)
       ```

    5. **Summary Row:**
       - Three values in HStack with operators
       - Nutrition value (blue icon + value)
       - Minus operator
       - Expenditure/Targets value (checkmark icon + value)
       - Equals operator
       - Difference value (positive green, negative red, or neutral)
       - Labels below each value: "Nutrition", "Expenditure"/"Targets", "Difference"

    6. **Mock Data:**
       - Create `EnergyBalanceMockData` struct
       - 30 days of calorie data (varying 500-1500 range)
       - Average expenditure: ~1893 kcal
       - Average targets: ~1429 kcal
       - Calculate totals for summary display

    7. **Segment Control:**
       - Similar style to HeroWidgetContainer's toggle
       - Options: "Expenditure" / "Targets"
       - Affects reference line value and summary calculation

    8. **Accessibility:**
       - `.accessibilityIdentifier("energy-balance-hero-widget")`
       - Chart accessibility label describing the trend

    **Padding:** Match other widgets: `.padding(.horizontal, 24)`, `.padding(.top, 20)`, `.padding(.bottom, 12)`
