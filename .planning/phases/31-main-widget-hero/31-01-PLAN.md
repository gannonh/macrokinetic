  <name>Task 1: Create DailyNutritionHeroWidget with circular ring and macro bars</name>
  <files>JabTracker/Views/Dashboard/Widgets/DailyNutritionHeroWidget.swift</files>
  <action>
    Create hero widget following WeeklyNutritionHeroWidget patterns:

    1. **Widget Structure** (DashboardWidget protocol):
       - `id = "daily-nutrition"`
       - `title = "Daily Nutrition"`
       - Implement `content` computed property

    2. **Layout (match Figma exactly):**
       - Title "Daily Nutrition" at top (same style as Weekly: 15pt semibold)
       - Large circular ring center (use custom implementation, NOT CircularProgressRing - need different center content)
       - Ring should be ~160pt diameter with ~12pt stroke
       - Ring color: `DesignTokens.Colors.calories` (teal)
       - Center text: Large value (36pt bold rounded) + small label below (11pt)
       - Left/Right stats flanking the ring: value (20pt bold) + label below (11pt secondary)

    3. **Center Ring Logic:**
       - Consumed mode: Center shows "{consumed} Consumed", left shows "{remaining} Remaining", right shows "{target} Target"
       - Remaining mode: Center shows "{remaining} Remaining", left shows "{consumed} Consumed", right shows "{target} Target"
       - Ring progress = consumed / target (capped at 1.0 for fill)

    4. **Macro Bars Section:**
       - Three horizontal progress bars (Protein, Fat, Carbs)
       - Each bar: colored label left, progress bar center, "X / Xg" text right
       - Bar colors: `.protein` (indigo), `.fat` (yellow), `.carbs` (orange)
       - Progress bars: 8pt height, rounded ends, inactive background
       - Layout similar to WeeklyMacroRow but horizontal bars not cells

    5. **Mock Data:**
       - Create `DailyMockData` struct following `WeeklyMockData` pattern
       - Calories: target 1395, consumed varies (partial fill for demo)
       - Protein: target 113g
       - Fat: target 49g
       - Carbs: target 125g
       - Today's partial consumption (40-60% filled)

    6. **Accept displayMode binding:**
       - Add `@Binding var displayMode: HeroDisplayMode` parameter
       - Switch display based on .consumed vs .remaining

    7. **Accessibility:**
       - `.accessibilityIdentifier("daily-nutrition-hero-widget")`
       - Combine ring and stats into accessible groups

    **Key differences from CircularProgressRing:**
    - Larger size (160pt vs 60pt default)
    - Different center content (value + label vs just percentage)
    - No label below ring (stats are beside it instead)

    **Padding:** Match Weekly widget: `.padding(.horizontal, 24)`, `.padding(.top, 20)`, `.padding(.bottom, 12)`

  <name>Task 2: Integrate DailyNutritionHeroWidget into carousel</name>
  <files>
    JabTracker/Views/Dashboard/Widgets/HeroWidgetContainer.swift,

  </files>
  <action>
    1. **Update HeroWidgetContainer to pass displayMode to widgets:**
       - Currently displayMode is internal @State
       - Widgets need to receive it to respond to toggle
       - Option A: Pass displayMode as environment value
       - Option B: Make pages closure-based to inject displayMode
       - **Choose Option A** - cleaner, widgets read from environment

       Add environment key:
       ```swift
       private struct HeroDisplayModeKey: EnvironmentKey {
           static let defaultValue: HeroDisplayMode = .consumed
       }

       extension EnvironmentValues {
           var heroDisplayMode: HeroDisplayMode {
               get { self[HeroDisplayModeKey.self] }
               set { self[HeroDisplayModeKey.self] = newValue }
           }
       }
       ```

       In HeroWidgetContainer, wrap TabView content:
       ```swift
       .environment(\.heroDisplayMode, displayMode)
       ```

    2. **Update DailyNutritionHeroWidget to use environment:**
       - Remove @Binding, use `@Environment(\.heroDisplayMode) var displayMode`

    3. **Update WeeklyNutritionHeroWidget:**
       - Add `@Environment(\.heroDisplayMode) var displayMode`
       - Use displayMode to toggle between consumed/remaining view
       - In consumed mode: show consumed values and fill
       - In remaining mode: show remaining values and fill (inverse)

    4. **Update ContentView.heroWidgetSection:**
       ```swift
       private var heroWidgetSection: some View {
           HeroWidgetContainer(pages: [
               AnyView(WeeklyNutritionHeroWidget()),
               AnyView(DailyNutritionHeroWidget())
           ])
       }
       ```
