# Phase 27: Simplified Goal & Program Setup

## Overview
Create streamlined goal/program selection screens for onboarding that are simpler than the full Strategy flow. Users select a goal type and program style, and the app creates a NutritionGoal + NutritionProgram with smart defaults.

## Architecture: Pragmatic Balance

### Approach
- Extend OnboardingViewModel with goal/program state (no separate ViewModels)
- Create simplified step views using extracted shared components
- Create GoalProgramService for smart defaults logic
- Reuse existing domain types (GoalType, ProgramStyle, NutritionGoal, NutritionProgram)

### Files to Create (7)
- `JabTracker/Onboarding/Views/GoalSetupStepView.swift` - Goal type selection
- `JabTracker/Onboarding/Views/ProgramSetupStepView.swift` - Program style selection
- `JabTracker/Design/StepHeader.swift` - Extracted shared component
- `JabTracker/Design/SelectionCard.swift` - Extracted shared component
- `JabTracker/Design/SummaryRow.swift` - Extracted shared component
- `JabTracker/Services/GoalProgramService.swift` - Smart defaults + save logic
- `JabTrackerUITests/Onboarding/OnboardingGoalProgramUITests.swift` - E2E tests

### Files to Modify (4)
- `JabTracker/Onboarding/OnboardingViewModel.swift` - Add goal/program state
- `JabTracker/Onboarding/OnboardingView.swift` - Route to new steps
- `JabTracker/Views/Nutrition/GoalWizard+Steps.swift` - Use extracted components
- `JabTracker/Views/Nutrition/ProgramWizardStepViews.swift` - Use extracted components
