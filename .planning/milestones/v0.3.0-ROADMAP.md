# Milestone v0.3.0: Goals & Nutrition Programs

**Status:** ✅ SHIPPED 2026-01-02
**Phases:** 12-17 (including 15.1, 15.2)
**Total Plans:** 20

## Overview

Personalized weight and macro goals with three program styles (Coached/Collaborative/Manual), diet preferences, adaptive TDEE engine, daily progress tracking with visual indicators, and weekly check-ins for goal/program adjustments.

## Phases

### Phase 12: Goal Data Model

**Goal:** SwiftData models for goals, nutrition programs, and TDEE tracking
**Depends on:** Previous milestone complete
**Plans:** 2 plans

Plans:
- [x] 12-01: Data Foundation - Enums and value types (ProgramConfiguration.swift)
- [x] 12-02: SwiftData Models - NutritionGoal, NutritionProgram, User integration

### Phase 14: Adaptive TDEE Engine

**Goal:** Personalized metabolic rate calculation from weight history with trend smoothing
**Depends on:** Phase 13
**Plans:** 3 plans

Plans:
- [x] 14-01: TDEE data foundation - User height/gender, TrainingLevel multipliers, TDEECalculationEngine
- [x] 14-02: Adaptive TDEE calculations - EWMA smoothing, confidence scoring, metabolic adaptation
- [x] 14-03: TDEEService orchestration - Initial/adaptive TDEE, goal updates, recalculation scheduling

**Details:**
- Mifflin-St Jeor BMR formula with activity multipliers
- EWMA (Exponential Weighted Moving Average) for weight trend smoothing
- 28-day weight/food history for adaptive calculations
- Confidence scoring with 70% threshold for TDEE changes
- Weekly recalculation scheduling

## Milestone Summary

**Decimal Phases:**
- Phase 15.1: Initial TDEE Integration (inserted after Phase 15 for urgent TDEE wiring)
- Phase 15.2: Program Style Implementation (inserted for Collaborative/Manual modes)

**Key Decisions:**

| Phase | Decision | Rationale |
|-------|----------|-----------|
| 12-01 | MacroPercentages struct instead of tuple | SwiftLint large_tuple compliance, cleaner API |
| 13-01 | Extended file_length SwiftLint for Nutrition views | Wizard contains 7 inline step views per architecture |
| 13-02 | Separate Goal and Program into distinct wizards | Mock review revealed incorrect domain coupling |
| 14-01 | Empty string default for gender | CloudKit compatibility; unknown averages male/female BMR |
| 15-01 | 70pt rings with 6pt line width, consumed inside | Compact display fits 4 rings on iPhone SE |
| 15.1-02 | DispatchQueue 0.35s delay for sheet chaining | Minimal code change ensures dismissal animation completes |
| 15.2-01 | WeeklyConstants enum for shared validWeekdayRange | DRY principle across distribution types |
| 15.2-04 | CollaborativeDayConfig struct for per-day state | Holds calories, protein, carb:fat, isLocked |
| 16-01 | Default check-in day to Monday (weekday=2) | Common weekly planning pattern |

**Issues Resolved:**
- Fixed Collaborative TDEE showing wrong calories - training level default changed to `.lifting`
- Fixed Edit Goal flow - ProgramSummarySheet/ProgramReadySheet now use @Query goal
- Added recalculateProgramTargets() for goal edit updates
- Sheet chaining race condition fixed with 0.35s delay

**Issues Deferred:**
- None

**Technical Debt Incurred:**
- None - all phases completed cleanly
