# Milestone v0.9.0: Improvements & Fixes

**Status:** ✅ SHIPPED 2026-01-17
**Phases:** 39-43
**Total Plans:** 8 (+4 FIX plans)

## Overview

Address analytics accuracy issues and enhance GLP-1 medication tracking UX. Focus on fixing calculation bugs (2416% steady state, energy balance averages, next dose projection) and adding missing features (day status tracking, adjustable doses, serving unit validation).

## Milestone Summary

**Key Decisions:**
- Day Status: DayStatus model per day differentiates fasting vs unknown days
- Dose Adjustment: Stepper with medication-specific therapeutic bounds
- Progress API: Decimals (0.0-1.0) not percentages; UI formats display
- Serving Validation: Density thresholds (cup: 80-300g) detect suspicious mappings
- Schedule Projection: From last taken dose for accurate next dose

**Issues Resolved:**
- Fixed 2416% steady state progress bug (unit mismatch)
- Fixed energy balance hero showing inflated deficits for new users
- Fixed next dose schedule off by 3+ days for weekly schedules
- Fixed serving unit mappings showing unrealistic gram values

**Technical Debt Incurred:**
- Phase 36 (Search Ranking) still deferred from v0.8.0
