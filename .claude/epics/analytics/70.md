# ChartConfiguration: Reduce Code Duplication with Builder Pattern

**Source:** PR #64 Review Comment

**Location:** JabTracker/Views/Analytics/ChartConfiguration.swift around lines 14 to 59
**Severity:** Medium - DRY principle violation

## Issue Description

The builder methods repeat full `ConcentrationChartConfiguration` initialization, leading to code duplication across 3 methods (`withTimeRange`, `withTheme`, `withInteractionSettings`).

**Current Pattern (Duplicated):**
```swift
// Same 8-parameter constructor repeated in each method
ConcentrationChartConfiguration(
    timeRange: timeRange,
    concentrationRange: self.concentrationRange,
    // ... 6 more identical parameters
)
```

## Recommended Solution

Introduce a private helper (e.g., `copyWith(...)`) that:
- Takes optional parameters for each overridable property
- Returns a new `ConcentrationChartConfiguration` using `self` for any `nil` params
- Refactor `withTimeRange(_:)`, `withTheme(_:)`, and `withInteractionSettings(_:)` to call this helper

## Implementation Requirements
- Helper preserves existing values when options are `nil`
- Keep method signatures and return types unchanged
- Maintain builder pattern functionality
- **Estimated Effort:** 3-4 hours
- **Impact:** Reduced maintenance burden

## Acceptance Criteria
