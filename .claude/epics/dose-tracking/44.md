## Overview

Add search bar and filter options to the dose history view for better dose discovery and organization.

## Requirements

### Search Functionality
- **Text Search**: Search dose notes, medication names, injection sites
- **Real-time Results**: Filter results as user types
- **Search Scope**: Include all dose fields and related medication data
- **Clear Search**: Easy way to clear search and return to full list

### Filter Options
- **Date Range**: Filter by custom date ranges or presets (today, week, month)
- **Medication Type**: Filter by specific medications
- **Injection Site**: Filter by injection location
- **Dose Amount**: Filter by dose ranges
- **Multiple Filters**: Combine multiple filter criteria

### UI Components
- **Search Bar**: Native searchable modifier integration
- **Filter Sheet**: Slide-up sheet with filter options
- **Active Filters**: Visual indicators of applied filters
- **Results Count**: Show number of filtered results

## Technical Implementation

### New Components
```swift
// DoseSearchBar.swift
struct DoseSearchBar: View {
    @Binding var searchText: String
    @Binding var showingFilters: Bool
    
    // Search field with filter button
    // Clear search functionality
}

// DoseFilterSheet.swift
struct DoseFilterSheet: View {
    @Binding var filters: DoseFilters
    @Binding var isPresented: Bool
    
    // Date range picker
    // Medication selection
    // Site and amount filters
}

// DoseFilters.swift
struct DoseFilters {
    var dateRange: DateRange?
    var medications: Set<String>
    var injectionSites: Set<String>
    var doseRange: ClosedRange<Double>?
    
    func matches(_ dose: Dose) -> Bool
}
```

### Modifications
```swift
// DoseHistoryView.swift - Add search and filter
.searchable(text: $searchText)
.sheet(isPresented: $showingFilters) {
    DoseFilterSheet(filters: $filters, isPresented: $showingFilters)
}

// Filtered dose list logic
var filteredDoses: [Dose] {
    doses
        .filter { filters.matches($0) }
        .filter { searchText.isEmpty || matchesSearch($0) }
}
```
