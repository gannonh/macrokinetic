## Overview

Connect dose logging to pharmacokinetics calculations by integrating the PharmacokineticsEngine with dose entry and dashboard display.

## Requirements

### Real-time Calculations
- **Concentration Updates**: Recalculate drug levels when new dose logged
- **Dashboard Integration**: Show current concentration on main dashboard
- **Automatic Refresh**: Update calculations when viewing dashboard
- **Multiple Medications**: Handle calculations for user's active medications

### Dashboard Display
- **Current Level**: Show real-time drug concentration
- **Peak/Trough**: Display upcoming peak and trough levels
- **Steady State**: Progress toward steady-state concentration
- **Next Dose**: Time until next scheduled dose with projected levels

### Calculation Engine
- **PharmacokineticsEngine**: Core calculation service
- **Exponential Decay**: Implement half-life based concentration decay
- **Multi-dose Modeling**: Calculate cumulative effects of multiple doses
- **Medication-specific**: Use correct half-life for each medication type

// PharmacokineticsEngine.swift - Implement core calculations
class PharmacokineticsEngine: ObservableObject {
    func calculateCurrentConcentration(for user: User, medication: MedicationProfile) -> Double

    func calculateTroughLevel(for medication: MedicationProfile) -> (level: Double, time: Date)
    func calculateSteadyStateProgress(for medication: MedicationProfile) -> Double
    func projectFutureLevels(for medication: MedicationProfile, days: Int) -> [ConcentrationPoint]
}

    let concentration: Double
}
