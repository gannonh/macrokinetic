# Task: Photo Attachments

## Description

Implement PhotosUI integration for dose photo attachments with size limits and proper image handling in the dose entry form.

## Requirements

### Photo Attachment Features
- **PhotosUI Integration**: Use PhotosPicker for image selection
- **Image Size Limits**: Compress images to reasonable size for storage
- **Multiple Format Support**: JPEG, PNG, HEIC handling
- **Preview Functionality**: Show selected image in dose entry form
- **Storage Integration**: Save image data to Dose model imageData field

### UI Components
- **Photo Selection Button**: Clean button to trigger photo picker
- **Image Preview**: Display selected photo with edit/remove options
- **Size Indicator**: Show image size after compression
- **Error Handling**: Handle permission denial and storage errors
