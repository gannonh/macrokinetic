# Dose Entry Form

## Overview
Create a comprehensive dose entry sheet that reuses existing MedicationFormComponents for consistency and allows detailed dose logging with all necessary fields.

## Requirements

### Core Functionality
- Sheet presentation for dose entry form
- Reuse MedicationFormComponents for consistent UI
- Support both quick entry and detailed entry modes
- Real-time validation with user-friendly error messages
- Integration with existing Dose SwiftData model

### Form Fields
- **Date & Time**: DatePicker with default to current time
- **Dose Amount**: Numeric input with medication-specific validation
- **Injection Site**: Picker using existing injection site options
- **Notes**: Optional text field for user comments
- **Photo**: Optional photo attachment using PhotosUI
- **Medication Profile**: Automatic selection from user's active profiles

### User Experience
- Smooth sheet animations and transitions
- Keyboard handling and dismissal
- Save/Cancel actions with confirmation
- Loading states for save operations
- Haptic feedback for successful saves

## Technical Implementation

### Files to Create
- `DoseEntrySheet.swift` - Main dose entry form sheet
- `DoseEntryViewModel.swift` - Business logic and validation

### Files to Modify
- `MedicationFormComponents.swift` - Extend with dose-specific components
- `AddDoseView.swift` - Integrate sheet presentation

### SwiftData Integration
- Create new Dose entity with all form data
- Link to appropriate MedicationProfile
- Handle relationship updates

### Validation Rules
- Dose amount must be within medication's available doses
- Date cannot be in the future
- Required fields must be populated
- Photo size limits and format validation
