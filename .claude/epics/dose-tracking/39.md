# Task: Quick Dose Entry

## Description
Implement quick dose entry by making the existing "+" (Add) tab button open a sheet or mini sheet for streamlined dose logging with smart defaults. This feature allows users to quickly log their scheduled doses using the familiar tab bar "+" button pattern, improving medication adherence tracking.

## Acceptance Criteria
- [ ] "+" (Add) tab button opens QuickDoseSheet when tapped
- [ ] QuickDoseSheet presents as sheet or mini sheet with streamlined interface
- [ ] Sheet pre-populates with smart defaults (current medication, dose amount, current time)
- [ ] Simple form allows quick entry with minimal required fields
- [ ] Visual feedback confirms successful dose logging (animation, haptic feedback)
- [ ] Integration with existing medication profiles for dose amount defaults
- [ ] Accessibility support with VoiceOver labels and actions
- [ ] Error handling for edge cases (no medication profile, sync failures)
- [ ] Sheet dismisses automatically after successful dose logging

## Technical Details
- Implementation approach: Sheet-based quick entry using existing tab bar "+" button
- Key files affected:
  - `ContentView.swift` or main tab navigation - Handle "+" tab button tap to present sheet
  - `QuickDoseSheet.swift` (new) - Sheet component with streamlined dose entry form
  - `QuickDoseViewModel.swift` (new) - Business logic for smart defaults and dose saving
- Use DataController dose creation methods from task 001
- Follow design system patterns with DesignTokens and accessibility
- Implement proper loading states and error presentation within sheet
- Consider daily dose frequency logic (weekly vs daily medications)
- Sheet presentation style (full sheet vs. mini sheet) for optimal UX
