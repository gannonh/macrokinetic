# Calendar Integration

## Overview
Add a calendar view with dose indicators and monthly statistics to provide users with a visual timeline of their dose tracking history and adherence patterns.

## Requirements

### Core Functionality
- Monthly calendar view with dose indicators
- Navigation between months/years
- Tap-to-view dose details for specific dates
- Monthly statistics summary
- Visual adherence indicators
- Integration with existing History tab

### Calendar Display
- **Dose Indicators**: Visual markers for days with doses
- **Multiple Doses**: Special indicators for days with multiple doses
- **Missed Doses**: Visual indicators for scheduled but missed doses
- **Injection Sites**: Color coding or icons for different injection sites
- **Photo Indicators**: Small icon for doses with photos
- **Today Highlighting**: Clear indication of current date

### Monthly Statistics
- **Total Doses**: Count of doses taken in month
- **Adherence Rate**: Percentage of scheduled doses taken
- **Streak Information**: Current and longest adherence streaks
- **Site Rotation**: Distribution of injection sites used
- **Average Dose**: Mean dose amount for the month

### User Interactions
- Tap date to view all doses for that day
- Long press for quick add dose on selected date
- Swipe or button navigation between months
- Smooth animations for month transitions
- Pull-to-refresh for data updates

## Technical Implementation

### Files to Create
- `DoseCalendarView.swift` - Main calendar component
- `DoseCalendarViewModel.swift` - Calendar business logic and statistics
- `CalendarDayView.swift` - Individual calendar day cell
- `MonthlyStatsView.swift` - Monthly statistics summary
- `DoseDayDetailView.swift` - Detail view for selected date

### Files to Modify
- `HistoryView.swift` - Add segmented control for list/calendar view toggle
- `DoseHistoryViewModel.swift` - Extend with calendar data methods

### Calendar Implementation
- Use UICalendar or custom SwiftUI calendar implementation
- Efficient data loading for visible month range
- Lazy loading for month navigation
- Proper date handling across time zones

### Statistics Calculations

- Site rotation analysis
- Monthly aggregation functions
