# Task 007: Split-Dose Support

## Objective
Implement split-dose scheduling calculations and UI configuration, enabling users to divide weekly medication doses into multiple administrations (e.g., 2mg weekly → 1mg twice weekly). Provide concentration curve comparison and offset validation.

## Context
**Why**: Split-dose patterns improve medication adherence and concentration stability for some patients. Medical literature supports twice-weekly administration for certain GLP-1 medications as alternative to single weekly dose.

**Dependencies**:
- Requires ScheduleService core calculations (Task 002)
- Can run parallel with UI integration tasks (004, 005, 006) as it extends service layer

**Related Files**:
- `JabTracker/Services/ScheduleService.swift` (extend)
- `JabTracker/Models/DoseSchedule.swift` (extend)
- `JabTracker/Services/PharmacokineticsEngine.swift` (use for concentration comparison)

**Location**: `JabTracker/Services/ScheduleService.swift`

```swift
extension ScheduleService {
    /// Create split-dose schedule configuration
    /// - Parameters:
    ///   - totalWeeklyDose: Total dose per week (e.g., 2.0mg)
    ///   - dosesPerWeek: Number of doses to split into (2-7)
    ///   - offsetDays: Optional custom offset (e.g., [0, 3] for Mon/Thu pattern)
    /// - Returns: SplitDoseConfig with calculated individual doses and offsets
    func createSplitDoseConfig(
        totalWeeklyDose: Double,
        dosesPerWeek: Int,
        customOffsets: [Double]? = nil
    ) throws -> SplitDoseConfig {
        // Validate inputs
        guard dosesPerWeek >= 2 && dosesPerWeek <= 7 else {
            throw ScheduleError.invalidFrequency(dosesPerWeek)
        }

        guard totalWeeklyDose > 0 else {
            throw ScheduleError.invalidDose(totalWeeklyDose)
        }

        // Calculate individual dose amount
        let individualDose = totalWeeklyDose / Double(dosesPerWeek)

        // Calculate or validate offsets
        let offsets: [Double]
        if let customOffsets = customOffsets {
            // Validate custom offsets
            guard customOffsets.count == dosesPerWeek else {
                throw ScheduleError.offsetCountMismatch
            }
            guard customOffsets.allSatisfy({ $0 >= 0 && $0 < 7 }) else {
                throw ScheduleError.invalidOffset
            }
            offsets = customOffsets.sorted()
        } else {
            // Calculate equal-split offsets
            offsets = (0..<dosesPerWeek).map { index in
                Double(index) * (7.0 / Double(dosesPerWeek))
            }
        }

        return SplitDoseConfig(
            totalWeeklyDose: totalWeeklyDose,
            dosesPerWeek: dosesPerWeek,
            individualDose: individualDose,
            offsets: offsets
        )
    }

    /// Calculate concentration curves for split-dose vs single-dose comparison
    /// - Parameters:
    ///   - splitConfig: Split-dose configuration
    ///   - medication: Medication for PK calculations
    ///   - days: Number of days to project
    /// - Returns: ComparisonCurves with both patterns
    func compareConcentrationCurves(
        splitConfig: SplitDoseConfig,
        medication: Medication,
        days: Int = 30
    ) -> ConcentrationCurveComparison {
        let pkEngine = PharmacokineticsEngine()

        // Create single-dose schedule (once weekly)
        let singleDoseSchedule = createSampleSchedule(
            pattern: .weekly,
            doseAmount: splitConfig.totalWeeklyDose,
            medication: medication
        )

        // Create split-dose schedule
        let splitDoseSchedule = createSampleSchedule(
            pattern: .splitDose,
            config: splitConfig,
            medication: medication
        )

        // Calculate concentration curves
        let singleDoseCurve = pkEngine.calculateConcentrationCurve(
            schedule: singleDoseSchedule,
            days: days
        )

        let splitDoseCurve = pkEngine.calculateConcentrationCurve(
            schedule: splitDoseSchedule,
            days: days
        )

        // Calculate peak and trough for both
        let singlePeak = singleDoseCurve.max(by: { $0.concentration < $1.concentration })?.concentration ?? 0
        let singleTrough = singleDoseCurve.min(by: { $0.concentration < $1.concentration })?.concentration ?? 0

        let splitPeak = splitDoseCurve.max(by: { $0.concentration < $1.concentration })?.concentration ?? 0
        let splitTrough = splitDoseCurve.min(by: { $0.concentration < $1.concentration })?.concentration ?? 0

        return ConcentrationCurveComparison(
            singleDoseCurve: singleDoseCurve,
            splitDoseCurve: splitDoseCurve,
            singlePeak: singlePeak,
            singleTrough: singleTrough,
            splitPeak: splitPeak,
            splitTrough: splitTrough,
            peakReduction: ((singlePeak - splitPeak) / singlePeak) * 100,
            troughIncrease: ((splitTrough - singleTrough) / singleTrough) * 100
        )
    }

    /// Validate split-dose configuration for medical accuracy
    func validateSplitDoseConfig(_ config: SplitDoseConfig) throws {
        // Ensure total dose consistency
        let calculatedTotal = config.individualDose * Double(config.dosesPerWeek)
        let tolerance = 0.01 // Allow 0.01mg variance for floating-point precision

        guard abs(calculatedTotal - config.totalWeeklyDose) < tolerance else {
            throw ScheduleError.doseCalculationMismatch(
                expected: config.totalWeeklyDose,
                calculated: calculatedTotal
            )
        }

        // Validate offsets are properly spaced
        for i in 0..<config.offsets.count - 1 {
            let spacing = config.offsets[i + 1] - config.offsets[i]
            guard spacing >= 1.0 else { // Minimum 1 day between doses
                throw ScheduleError.insufficientDoseSpacing(spacing)
            }
        }
    }
}

// MARK: - Supporting Types

struct SplitDoseConfig {
    let totalWeeklyDose: Double
    let dosesPerWeek: Int
    let individualDose: Double
    let offsets: [Double]

    var description: String {
        "\(totalWeeklyDose)mg weekly → \(individualDose)mg × \(dosesPerWeek)"
    }
}

struct ConcentrationCurveComparison {
    let singleDoseCurve: [ConcentrationPoint]
    let splitDoseCurve: [ConcentrationPoint]
    let singlePeak: Double
    let singleTrough: Double
    let splitPeak: Double
    let splitTrough: Double
    let peakReduction: Double  // Percentage
    let troughIncrease: Double  // Percentage
}

enum ScheduleError: LocalizedError {
    case invalidFrequency(Int)
    case invalidDose(Double)
    case offsetCountMismatch
    case invalidOffset
    case doseCalculationMismatch(expected: Double, calculated: Double)
    case insufficientDoseSpacing(Double)

    var errorDescription: String? {
        switch self {
        case .invalidFrequency(let freq):
            return "Invalid frequency: \(freq). Must be between 2-7 doses per week."
        case .invalidDose(let dose):
            return "Invalid dose amount: \(dose)mg. Must be greater than 0."
        case .offsetCountMismatch:
            return "Number of custom offsets must match doses per week."
        case .invalidOffset:
            return "Offsets must be between 0-7 days."
        case .doseCalculationMismatch(let expected, let calculated):
            return "Dose calculation mismatch: expected \(expected)mg, calculated \(calculated)mg"
        case .insufficientDoseSpacing(let spacing):
            return "Doses must be at least 1 day apart (current: \(spacing) days)"
        }
    }
}
```

```swift
extension DoseSchedule {
    /// For split-dose patterns, store the total weekly dose
    var totalWeeklyDose: Double? {
        guard pattern == .splitDose else { return nil }
        return scheduledDoses.reduce(0) { $0 + $1.doseAmount }
    }

    /// Calculate individual dose amount for split-dose pattern
    var splitDoseIndividualAmount: Double? {
        guard pattern == .splitDose, frequency > 0 else { return nil }
        return totalWeeklyDose.map { $0 / Double(frequency) }
    }

    /// Get split-dose configuration summary
    var splitDoseConfig: SplitDoseConfig? {
        guard pattern == .splitDose,
              let total = totalWeeklyDose,
              let individual = splitDoseIndividualAmount else {
            return nil
        }

        let offsets = scheduledDoses.map { $0.offsetDays }.sorted()

        return SplitDoseConfig(
            totalWeeklyDose: total,
            dosesPerWeek: frequency,
            individualDose: individual,
            offsets: offsets
        )
    }
}
```

```swift
struct SplitDoseConfigurationView: View {
    @Binding var totalWeeklyDose: Double
    @Binding var dosesPerWeek: Int
    @Binding var customOffsets: [Double]?

    let medication: Medication
    let scheduleService: ScheduleService

    @State private var curveComparison: ConcentrationCurveComparison?
    @State private var useCustomOffsets: Bool = false
    @State private var validationError: String?

    var body: some View {
        VStack(alignment: .leading, spacing: 20) {
            // Split-dose configuration
            VStack(alignment: .leading, spacing: 12) {
                Text("Split-Dose Configuration")
                    .font(.headline)

                // Total weekly dose display
                HStack {
                    Text("Total Weekly Dose:")
                    Spacer()
                    Text("\(totalWeeklyDose, specifier: "%.2f") mg")
                        .fontWeight(.semibold)
                }

                // Doses per week stepper
                Stepper("Doses per week: \(dosesPerWeek)", value: $dosesPerWeek, in: 2...4)
                    .onChange(of: dosesPerWeek) { _, _ in
                        updateConcentrationComparison()
                    }

                // Individual dose calculation
                HStack {
                    Text("Individual Dose:")
                    Spacer()
                    Text("\(totalWeeklyDose / Double(dosesPerWeek), specifier: "%.2f") mg")
                        .foregroundColor(.secondary)
                }
            }
            .padding()
            .background(
                RoundedRectangle(cornerRadius: 12)
                    .fill(Color.gray.opacity(0.05))
            )

            // Custom offsets toggle
            Toggle("Custom Schedule Pattern", isOn: $useCustomOffsets)
                .onChange(of: useCustomOffsets) { _, _ in
                    customOffsets = useCustomOffsets ? calculateDefaultOffsets() : nil
                }

            if useCustomOffsets {
                CustomOffsetEditor(
                    offsets: Binding(
                        get: { customOffsets ?? calculateDefaultOffsets() },
                        set: { customOffsets = $0 }
                    ),
                    dosesPerWeek: dosesPerWeek
                )
            }

            // Validation error
            if let error = validationError {
                Text(error)
                    .font(.caption)
                    .foregroundColor(.red)
            }

            // Concentration curve comparison
            if let comparison = curveComparison {
                ConcentrationComparisonChart(comparison: comparison)
            }
        }
        .task {
            updateConcentrationComparison()
        }
    }

    private func calculateDefaultOffsets() -> [Double] {
        (0..<dosesPerWeek).map { index in
            Double(index) * (7.0 / Double(dosesPerWeek))
        }
    }

    private func updateConcentrationComparison() {
        Task {
            do {
                let config = try scheduleService.createSplitDoseConfig(
                    totalWeeklyDose: totalWeeklyDose,
                    dosesPerWeek: dosesPerWeek,
                    customOffsets: customOffsets
                )

                try scheduleService.validateSplitDoseConfig(config)

                curveComparison = scheduleService.compareConcentrationCurves(
                    splitConfig: config,
                    medication: medication,
                    days: 21
                )

                validationError = nil
            } catch {
                validationError = error.localizedDescription
            }
        }
    }
}
```

```swift
struct ConcentrationComparisonChart: View {

    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            Text("Concentration Comparison")
                .font(.headline)

            // Chart
            Chart {

                ForEach(comparison.singleDoseCurve) { point in

                        x: .value("Day", point.date),
                        y: .value("Concentration", point.concentration)
                    )
                    .foregroundStyle(.blue.opacity(0.6))
                    .lineStyle(StrokeStyle(lineWidth: 2, dash: [5, 3]))

                // Split-dose curve
                ForEach(comparison.splitDoseCurve) { point in
                    LineMark(
                        x: .value("Day", point.date),
                        y: .value("Concentration", point.concentration)
                    )
                    .foregroundStyle(.green)
                    .lineStyle(StrokeStyle(lineWidth: 2))
                }
            }
            .chartYScale(domain: 0...(max(comparison.singlePeak, comparison.splitPeak) * 1.1))
            .frame(height: 200)

            // Legend
            HStack(spacing: 20) {
                Label {
                    Text("Once Weekly")
                } icon: {
                    Rectangle()
                        .fill(.blue.opacity(0.6))
                        .frame(width: 20, height: 2)
                }
                .font(.caption)

                Label {
                    Text("Split Dose")
                } icon: {
                    Rectangle()
                        .fill(.green)
                        .frame(width: 20, height: 2)
                }
                .font(.caption)
            }

            // Statistics
            VStack(spacing: 12) {
                StatComparisonRow(
                    label: "Peak Reduction",
```

```swift
struct CustomOffsetEditor: View {
    @Binding var offsets: [Double]
    let dosesPerWeek: Int

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            Text("Custom Pattern")
                .font(.subheadline)
                .foregroundColor(.secondary)

            ForEach(0..<dosesPerWeek, id: \.self) { index in
                HStack {
                    Text("Dose \(index + 1)")
                        .font(.subheadline)
                    Spacer()

                    // Day of week picker
                    Picker("Day", selection: Binding(
                        get: { Int(offsets[index]) },
                        set: { offsets[index] = Double($0) }
                    )) {
                        ForEach(0..<7) { day in
                            Text(dayName(for: day)).tag(day)
                        }
                    }
                    .pickerStyle(.menu)
                }
            }
        }
        .padding()
        .background(
            RoundedRectangle(cornerRadius: 12)
                .fill(Color.blue.opacity(0.05))
        )
    }

    private func dayName(for offset: Int) -> String {
        let weekdays = ["Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"]
        return weekdays[offset % 7]
    }
}
```

## Implementation Notes

### Technical Considerations
1. **Floating-Point Precision**: Use 0.01mg tolerance for dose calculations to handle floating-point arithmetic limitations. Medical accuracy critical - test edge cases.

2. **Offset Calculation**: Equal-split uses simple division (7 days / dosesPerWeek). For 2 doses: [0, 3.5]. For 3 doses: [0, 2.33, 4.66]. Round to 2 decimal places for display, store precise values.

3. **PK Engine Integration**: Reuse existing PharmacokineticsEngine for concentration calculations. Generate sample doses at calculated offsets to feed into engine.

4. **Concentration Comparison**: Calculate both curves over 21 days (3 weeks) to show steady-state convergence. Display overlaid on same chart with distinct styling.

5. **Custom Offsets**: Support custom patterns (e.g., Monday/Thursday = [1, 4] days from Sunday). Validate minimum 1-day spacing to prevent double-dosing scenarios.

6. **Medical Safety**: Validate that sum of individual doses equals total weekly dose. Prevent configurations that could result in overdosing or underdosing.

### Edge Cases
1. **Unequal Division**: 2mg ÷ 3 doses = 0.666666...mg - round to 0.67mg, display warning about rounding
2. **Maximum Frequency**: Limit to 4 doses per week for split-dose (daily dosing is separate pattern)
3. **Custom Offset Conflicts**: Prevent offsets that would schedule 2 doses on same day
4. **Medication Limitations**: Not all medications support split-dose - validate against medication properties
