# Task 008: Analytics Integration - Schedule Adherence Tracking & Timeline View

## Description
Extend AnalyticsService with schedule-aware adherence tracking and create ScheduleTimelineView for visualizing upcoming scheduled doses alongside historical concentration data. This integration provides comprehensive medication management insights combining past adherence, current concentration, and future scheduled doses.

## Context
- Builds on AnalyticsService foundation from analytics epic (Issue #59)
- Requires ScheduleModel from Task 001 for schedule metadata
- Requires ScheduleService from Task 002 for schedule calculations
- Requires SplitDoseScheduleView from Task 007 for split-dose schedule patterns
- Leverages existing ConcentrationTimelineChart as visualization foundation
- Integrates with PharmacokineticsEngine for projected concentration curves

## Technical Approach

### AnalyticsService Extensions
```swift
// JabTracker/Services/AnalyticsService+Scheduling.swift
extension AnalyticsService {
    /// Calculate schedule adherence rate (taken doses vs scheduled doses)
    func calculateScheduleAdherence(
        profile: MedicationProfile,
        dateRange: ClosedRange<Date>
    ) async -> ScheduleAdherenceMetrics

    /// Project future concentration curve based on scheduled doses
    func projectConcentrationCurve(
        profile: MedicationProfile,
        projectionDays: Int = 90
    ) async -> [ProjectedConcentrationPoint]

    /// Analyze schedule consistency (timing variability, missed windows)
    func analyzeScheduleConsistency(
        profile: MedicationProfile,
        dateRange: ClosedRange<Date>
    ) async -> ScheduleConsistencyAnalysis
}

struct ScheduleAdherenceMetrics {
    let adherenceRate: Double // % of scheduled doses taken
    let scheduledDoseCount: Int
    let takenDoseCount: Int
    let missedDoseCount: Int
    let averageTimingDeviation: TimeInterval // seconds from ideal time
    let longestStreak: Int // consecutive scheduled doses on time
    let currentStreak: Int
}

struct ScheduleConsistencyAnalysis {
    let timingVariability: TimeInterval // standard deviation of timing
    let preferredDoseTime: DateComponents? // most common dose time
    let missedWindowCount: Int // doses taken outside ideal window
    let insights: [ScheduleInsight]
}

struct ProjectedConcentrationPoint {
    let date: Date
    let concentration: Double
    let projectionType: ProjectionType

    enum ProjectionType {
        case historical // actual dose data
        case scheduled // projected from schedule
        case steady_state // steady-state projection
    }
}

struct ScheduleInsight: Identifiable {
    let id: UUID
    let type: InsightType
    let priority: Priority
    let message: String
    let actionableRecommendation: String?

    enum InsightType {
        case timing_improvement
        case schedule_optimization
        case adherence_risk
        case steady_state_prediction
    }
}
```

### Performance Optimization
- **Lazy Loading**: Load historical data first, project concentrations in background
- **Caching Strategy**: Cache projected concentration curves (invalidate on schedule changes)
- **Incremental Updates**: Only recalculate affected date ranges on schedule modifications
- **Background Calculation**: Use `Task.detached` for expensive concentration projections

## Implementation Notes

### Dependencies
- **Models**: ScheduleModel (Task 001) for schedule metadata
- **Services**: ScheduleService (Task 002) for schedule calculations
- **UI Components**: SplitDoseScheduleView (Task 007) for split-dose patterns
- **Analytics Foundation**: AnalyticsService from analytics epic (Issue #59)
- **Chart Foundation**: ConcentrationTimelineChart from Issue #56

### Technical Risks
- **Performance Risk**: Concentration projection with daily schedules (365 days × daily = 365 calculations)
  - Mitigation: Background calculation, caching, lazy loading
- **Accuracy Risk**: Projected concentration diverges from actual due to adherence variations
  - Mitigation: Clearly label projections as "based on perfect adherence"
- **Complexity Risk**: Integrating multiple schedule types (weekly, daily, split-dose) in analytics
  - Mitigation: Comprehensive test coverage, phased implementation

### Architecture Decisions
- **Extension Pattern**: Use AnalyticsService+Scheduling.swift extension for schedule-specific analytics
- **Projection Strategy**: Separate ProjectedConcentrationPoint type for clear historical vs projected differentiation
- **Chart Integration**: Extend existing ConcentrationTimelineChart rather than creating new chart component
- **Insight Generation**: Use ScheduleInsight struct pattern from AdherenceInsights (Issue #57)
