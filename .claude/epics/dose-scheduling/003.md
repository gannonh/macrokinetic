# Task 003: NotificationService - Smart Dose Reminders and Notification Management

## Description

Implement the `NotificationService` responsible for all notification management in the dose scheduling system. This service orchestrates dose reminder notifications, handles notification actions (take, skip, snooze), manages background refresh for notification queue updates, and detects missed doses for timely alerts.

The service integrates with iOS User Notifications framework, supports actionable notifications with inline responses, and maintains a 30-day rolling notification queue. Background refresh ensures notifications remain accurate even when the app isn't running.

### Notification Scheduling with 64-Notification Limit Handling
```swift
func refreshNotificationQueue() async throws {
    // Get upcoming doses from ScheduleService
    let upcomingDoses = scheduleService.upcomingDoses  // Already limited to 30 days

    // Cancel all existing notifications
    notificationCenter.removeAllPendingNotificationRequests()

    // Limit to 64 notifications (iOS constraint)
    let dosesToSchedule = Array(upcomingDoses.prefix(64))

    // Schedule notifications
    for scheduledDose in dosesToSchedule {
        try scheduleDoseReminder(for: scheduledDose)
    }

    // Update queue property
    let pending = await notificationCenter.pendingNotificationRequests()
    notificationQueue = pending.map { request in
        PendingNotification(
            id: request.identifier,
            scheduledDoseId: UUID(uuidString: request.content.userInfo["scheduledDoseId"] as! String)!,
            triggerDate: (request.trigger as! UNCalendarNotificationTrigger).nextTriggerDate()!,
            content: NotificationContent(
                title: request.content.title,
                body: request.content.body,
                categoryIdentifier: request.content.categoryIdentifier
            )
        )
    }
}
```

### Action Handling with SwiftData Integration
```swift
func handleNotificationAction(_ action: UNNotificationAction, for notification: UNNotification) async {
    guard let scheduledDoseIdString = notification.request.content.userInfo["scheduledDoseId"] as? String,
          let scheduledDoseId = UUID(uuidString: scheduledDoseIdString) else {
        logger.error("Invalid scheduledDoseId in notification userInfo")
        return
    }

    // Fetch ScheduledDose from SwiftData
    guard let scheduledDose = scheduleService.getScheduledDose(id: scheduledDoseId) else {
        logger.error("ScheduledDose not found for ID: \(scheduledDoseId)")
        return
    }

    switch action.identifier {
    case "TAKE_DOSE", "TAKE_NOW":
        // Create Dose entity and link to ScheduledDose
        do {
            let dose = Dose(
                medication: scheduledDose.schedule?.medicationProfile,
                amount: scheduledDose.doseAmount,
                timestamp: Date(),
                injectionSite: nil,  // Can prompt user in-app
                notes: "Taken via notification action"
            )
            try scheduleService.markDoseTaken(scheduledDose, actualDose: dose)
            logger.info("Dose taken via notification action")
        } catch {
            logger.error("Failed to mark dose taken: \(error)")
        }

    case "SKIP_DOSE", "SKIP_MISSED":
        // Mark ScheduledDose as skipped
        do {
            try scheduleService.skipDose(scheduledDose, reason: "User skipped via notification")
            logger.info("Dose skipped via notification action")
        } catch {
            logger.error("Failed to skip dose: \(error)")
        }

    case "SNOOZE":
        // Reschedule notification for +15 minutes
        let snoozeTime = Date().addingTimeInterval(15 * 60)
        try? scheduleDoseReminder(for: scheduledDose, reminderOffset: -snoozeTime.timeIntervalSince(scheduledDose.scheduledTime))
        logger.info("Dose reminder snoozed for 15 minutes")

    default:
        logger.warning("Unknown notification action: \(action.identifier)")
    }

    // Refresh notification queue and badge
    try? await refreshNotificationQueue()
    await updateBadgeCount()
}
```

## Risks and Mitigation
- **iOS Notification Limit**: 64 pending notifications maximum
  - *Mitigation*: Prioritize nearest doses, refresh queue as doses pass
- **Background Refresh Reliability**: iOS may not always grant background time
  - *Mitigation*: Queue refresh on app foreground as backup
- **Notification Delivery**: iOS may delay or drop notifications
  - *Mitigation*: Multiple notification strategies (before dose, missed dose alerts)
- **Action Handling Complexity**: SwiftData context access in delegate methods
  - *Mitigation*: Careful ModelContext management, error handling
