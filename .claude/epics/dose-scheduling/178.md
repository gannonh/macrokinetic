# Task 005: Calendar Integration

## Objective
Extend existing CalendarView to display scheduled dose indicators, differentiate between logged/scheduled/missed doses, and enable long-press actions for dose management (log, reschedule, skip).

## Context
**Why**: Calendar is the natural interface for visualizing scheduled vs actual doses. Users need to see upcoming scheduled doses and act on them directly from the calendar view.

**Dependencies**:
- Requires DoseSchedule and ScheduledDose models (Task 001)
- Requires ScheduleService for calculating scheduled doses in date range (Task 002)
- Extends existing CalendarView and StatisticsEngine

**Related Files**:
- `JabTracker/Views/History/CalendarView.swift` (extend)
- `JabTracker/Views/History/CalendarViewModel.swift` (extend)
- `JabTracker/Services/ScheduleService.swift` (use)
- `JabTracker/Services/StatisticsEngine.swift` (extend)

```swift
struct CalendarDayCell: View {
    let day: CalendarDay
    let loggedDoses: [Dose]
    let scheduledDoses: [DoseEvent]  // NEW
    let onDayTap: () -> Void
    let onDoseEventLongPress: (DoseEvent) -> Void  // NEW

    var body: some View {
        VStack(spacing: 4) {
            // Day number
            Text(day.dayNumber)
                .font(.system(size: 14, weight: day.isCurrentMonth ? .regular : .light))
                .foregroundColor(day.isCurrentMonth ? .primary : .secondary)

            // Dose indicators (logged + scheduled)
            DoseIndicatorsView(
                loggedCount: loggedDoses.count,
                scheduledEvents: scheduledDoses
            )
            .onLongPressGesture {
                // Handle long press on scheduled dose
                if let firstScheduled = scheduledDoses.first(where: { $0.status == .scheduled }) {
                    onDoseEventLongPress(firstScheduled)
                }
            }
        }
        .frame(height: 60)
        .background(
            RoundedRectangle(cornerRadius: 8)
                .fill(day.isToday ? Color.blue.opacity(0.1) : Color.clear)
        )
        .onTapGesture(perform: onDayTap)
        .accessibilityLabel(accessibilityLabel)
        .accessibilityHint(accessibilityHint)
    }

    private var accessibilityLabel: String {
        var label = "Day \(day.dayNumber)"

        if loggedDoses.count > 0 {
            label += ", \(loggedDoses.count) dose\(loggedDoses.count == 1 ? "" : "s") logged"
        }

        let scheduledCount = scheduledDoses.filter { $0.status == .scheduled }.count
        if scheduledCount > 0 {
            label += ", \(scheduledCount) dose\(scheduledCount == 1 ? "" : "s") scheduled"
        }

        let missedCount = scheduledDoses.filter { $0.status == .missedLate }.count
        if missedCount > 0 {
            label += ", \(missedCount) missed dose\(missedCount == 1 ? "" : "s")"
        }

        return label
    }

    private var accessibilityHint: String {
        if scheduledDoses.contains(where: { $0.status == .scheduled }) {
            return "Long press to manage scheduled dose"
        }
        return "Tap to view details"
    }
}
```

```swift
struct ScheduledDoseIndicator: View {
    let status: DoseStatus
    let size: CGFloat = 8

    var body: some View {
        Circle()
            .strokeBorder(indicatorColor, lineWidth: isFilled ? 0 : 2)
            .background(Circle().fill(isFilled ? indicatorColor : Color.clear))
            .frame(width: size, height: size)
    }

    private var indicatorColor: Color {
        switch status {
        case .scheduled:
            return .blue
        case .logged:
            return .blue
        case .missedLate:
            return .red
        case .skipped:
            return .gray
        case .rescheduled:
            return .orange
        }
    }

    private var isFilled: Bool {
        status == .logged
    }
}

struct DoseIndicatorsView: View {
    let loggedCount: Int
    let scheduledEvents: [DoseEvent]

    var body: some View {
        HStack(spacing: 4) {
            // Logged doses (filled circles)
            ForEach(0..<min(loggedCount, 3), id: \.self) { _ in
                ScheduledDoseIndicator(status: .logged)
            }

            // Scheduled doses (outlined circles)
            ForEach(scheduledEvents.prefix(3)) { event in
                ScheduledDoseIndicator(status: event.status)
            }

            // Overflow indicator if more than 3 total
            if loggedCount + scheduledEvents.count > 3 {
                Text("+\(loggedCount + scheduledEvents.count - 3)")
                    .font(.system(size: 8, weight: .medium))
                    .foregroundColor(.secondary)
            }
        }
        .frame(height: 12)
    }
}
```

```swift
struct RescheduleDoseSheet: View {
    let event: DoseEvent
    @Bindable var viewModel: CalendarViewModel
    let onRescheduled: () -> Void

    @State private var newDate: Date
    @Environment(\.dismiss) private var dismiss

    init(event: DoseEvent, viewModel: CalendarViewModel, onRescheduled: @escaping () -> Void) {
        self.event = event
        self.viewModel = viewModel
        self.onRescheduled = onRescheduled

        // Initialize with smart suggestion (+24 hours)
        _newDate = State(initialValue: event.scheduledDate.addingTimeInterval(24 * 60 * 60))
    }

    var body: some View {
        NavigationStack {
            Form {
                Section {
                    DatePicker(
                        "New Date & Time",
                        selection: $newDate,
                        in: Date()...,  // Prevent past dates
                        displayedComponents: [.date, .hourAndMinute]
                    )
                }

                Section("Quick Options") {
                    Button("Tomorrow, Same Time") {
                        newDate = Calendar.current.date(
                            byAdding: .day,
                            value: 1,
                            to: event.scheduledDate
                        ) ?? event.scheduledDate
                    }

                    Button("In 24 Hours") {
                        newDate = event.scheduledDate.addingTimeInterval(24 * 60 * 60)
                    }

                    Button("In 48 Hours") {
                        newDate = event.scheduledDate.addingTimeInterval(48 * 60 * 60)
                    }
                }
            }
            .navigationTitle("Reschedule Dose")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("Cancel") { dismiss() }
                }
                ToolbarItem(placement: .confirmationAction) {
                    Button("Reschedule") {
                        Task {
                            await viewModel.rescheduleDose(event, to: newDate)
                            onRescheduled()
                        }
                    }
                }
            }
        }
        .presentationDetents([.medium])
    }
}
```

```swift
extension CalendarViewModel {
    /// Get scheduled doses for a specific date
    func scheduledDoses(for date: Date) -> [DoseEvent] {
        scheduledDoseEvents.filter { event in
            Calendar.current.isDate(event.scheduledDate, inSameDayAs: date)
        }
    }

    /// Load scheduled doses for current month
    @MainActor
    func loadScheduledDoses() async {
        let startOfMonth = Calendar.current.date(
            from: Calendar.current.dateComponents([.year, .month], from: currentMonth)
        ) ?? currentMonth

        let endOfMonth = Calendar.current.date(
            byAdding: DateComponents(month: 1, day: -1),
            to: startOfMonth
        ) ?? currentMonth

        // Get all active schedules
        let activeSchedules = try? scheduleService.fetchActiveSchedules()

        // Calculate scheduled doses for month
        scheduledDoseEvents = activeSchedules?.flatMap { schedule in
            scheduleService.calculateScheduledDoses(
                for: schedule,
                from: startOfMonth,
                to: endOfMonth
            )
        } ?? []
    }

    /// Reschedule a dose event
    @MainActor
    func rescheduleDose(_ event: DoseEvent, to newDate: Date) async {
        do {
            try scheduleService.rescheduleEvent(event, to: newDate)
            await loadScheduledDoses()
        } catch {
            // Handle error - show alert
            print("Failed to reschedule dose: \(error)")
        }
    }

    /// Skip a dose event
    @MainActor
    func skipDose(_ event: DoseEvent) async {
        do {
            try scheduleService.skipEvent(event)
            await loadScheduledDoses()
        } catch {
            // Handle error
```

```swift
extension StatisticsEngine {
    /// Calculate schedule adherence for a month
    func calculateScheduleAdherence(
        scheduledDoses: [DoseEvent],
        loggedDoses: [Dose]
    ) -> Double {
        let scheduledCount = scheduledDoses.filter { $0.status == .scheduled || $0.status == .logged }.count
        guard scheduledCount > 0 else { return 1.0 }

        let loggedCount = scheduledDoses.filter { $0.status == .logged }.count
        return Double(loggedCount) / Double(scheduledCount)
    }

    /// Calculate schedule adherence statistics for display
    func scheduleAdherenceStats(
        scheduledDoses: [DoseEvent]
    ) -> ScheduleAdherenceStats {
        let total = scheduledDoses.count
        let logged = scheduledDoses.filter { $0.status == .logged }.count
        let missed = scheduledDoses.filter { $0.status == .missedLate }.count
        let skipped = scheduledDoses.filter { $0.status == .skipped }.count
        let scheduled = scheduledDoses.filter { $0.status == .scheduled }.count

        return ScheduleAdherenceStats(
            totalScheduled: total,
            logged: logged,
            missed: missed,
            skipped: skipped,
            upcoming: scheduled,
            adherenceRate: total > 0 ? Double(logged) / Double(total) : 0.0
        )
    }
}

struct ScheduleAdherenceStats {
    let totalScheduled: Int
    let logged: Int
    let missed: Int
    let skipped: Int
    let upcoming: Int
    let adherenceRate: Double
}
```

## Implementation Notes

### Technical Considerations
1. **Performance Optimization**: Load scheduled doses lazily per month. Don't calculate all future scheduled doses on calendar load. Use `loadScheduledDoses()` on month navigation.

2. **Long-Press vs Tap Gesture**: Long-press on calendar day with scheduled dose opens action sheet. Regular tap opens day detail view. Ensure gestures don't conflict.

3. **Indicator Layout**: Limit to 3 visible indicators per day. Show overflow count (+2) if more than 3 doses (logged + scheduled). Prevent layout overflow.

4. **QuickDoseSheet Integration**: Reuse existing QuickDoseSheet component. Pre-populate with scheduled dose details (medication profile, amount) when launched from calendar action.

5. **Schedule Refresh**: After dose actions (log, reschedule, skip), refresh calendar to show updated scheduled dose status. Avoid full calendar reload - update only affected dates.

6. **Missed Dose Detection**: ScheduleService detects missed doses by comparing scheduled date to current time. Missed doses appear as red indicators. Update calendar daily or on-open to refresh missed status.

### Edge Cases
1. **Multiple Scheduled Doses Per Day**: Split-dose scenarios may have 2+ scheduled doses per day. Show multiple indicators, handle in action sheet.
2. **Logged Dose Without Schedule**: User manually logged dose outside of schedule. Show filled indicator without outline.
3. **Schedule Modification**: If schedule modified (e.g., deactivated), reload calendar to remove future scheduled doses.
4. **Past Scheduled Doses**: Show missed status for unlogged past scheduled doses. Don't allow rescheduling to past dates.

### Accessibility Requirements
- Scheduled dose indicators have descriptive labels ("Scheduled dose at 10:00 AM")
- Action sheet buttons announce actions clearly
- VoiceOver gestures for long-press handled correctly
- Calendar day cells announce dose count and status
