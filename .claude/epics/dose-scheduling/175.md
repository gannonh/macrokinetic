# Task 002: ScheduleService Core - Schedule Management and Calculation Algorithms

## Description

Implement the centralized `ScheduleService` responsible for all dose scheduling business logic. This service orchestrates schedule CRUD operations, generates projected ScheduledDose entities for 30-day windows, calculates adherence metrics, and handles schedule modifications (reschedule, skip, pause/resume).

The service follows the established `@Observable` pattern and integrates with SwiftData for persistence. Performance is critical: 365-day schedule projections must complete in <100ms to support responsive UI interactions.

### Schedule Generation Algorithm (Weekly Pattern Example)
```swift
private func generateWeeklyDoses(config: ScheduleConfiguration, from: Date, to: Date, isPaused: Bool) -> [ScheduledDose] {
    var doses: [ScheduledDose] = []
    var currentDate = from

    while currentDate <= to {
        // Skip if schedule is paused during this period
        if isPaused && currentDate.isBetween(pausedAt, pausedUntil) {
            currentDate = Calendar.current.date(byAdding: .day, value: config.interval, to: currentDate)!
            continue
        }

        // Calculate scheduled time
        let scheduledTime = Calendar.current.date(
            bySettingHour: config.timeOfDay.hour,
            minute: config.timeOfDay.minute,
            second: 0,
            of: currentDate
        )!

        // Calculate window
        let windowStart = Calendar.current.date(byAdding: .minute, value: -config.windowMinutesBefore, to: scheduledTime)!
        let windowEnd = Calendar.current.date(byAdding: .minute, value: config.windowMinutesAfter, to: scheduledTime)!

        // Create ScheduledDose
        let scheduledDose = ScheduledDose(
            schedule: schedule,
            scheduledTime: scheduledTime,
            doseAmount: config.doseAmount,
            windowStart: windowStart,
            windowEnd: windowEnd
        )
        doses.append(scheduledDose)

        // Advance to next dose
        currentDate = Calendar.current.date(byAdding: .day, value: config.interval, to: currentDate)!
    }

    return doses
}
```

### Performance Optimization Strategies
- **Lazy Generation**: Generate ScheduledDose entities on-demand rather than persisting all future doses
- **30-Day Rolling Window**: Only keep upcoming doses in memory, generate more as needed
- **Batch Operations**: Use SwiftData batch inserts for large schedule projections
- **Caching**: Cache computed properties (nextScheduledDose) to avoid repeated queries
- **Query Optimization**: Use FetchDescriptor with predicates to minimize data loading
