# Task 006: Medication Profile CRUD

## Objective
Integrate schedule management into medication profile editing, enabling users to view, edit, pause, and deactivate dose schedules for existing medications. Display schedule history timeline and current schedule summary.

## Context
**Why**: Users need to modify schedules after initial setup (change reminder times, adjust patterns, pause during travel). Medication profile is the natural location for comprehensive schedule management.

**Dependencies**:
- Requires DoseSchedule and ScheduledDose models (Task 001)
- Requires ScheduleService CRUD operations (Task 002)
- Extends existing MedicationProfileEditView

**Related Files**:
- `JabTracker/Views/Settings/MedicationProfileEditView.swift` (extend)
- `JabTracker/Views/Settings/MedicationProfileViewModel.swift` (extend)
- `JabTracker/Services/ScheduleService.swift` (use)

```swift
                Divider()

                HStack(spacing: 12) {
                    Image(systemName: "exclamationmark.triangle.fill")
                        .foregroundColor(.orange)
                    VStack(alignment: .leading, spacing: 4) {
                        Text("Upcoming Dose Change")
                            .font(.caption)
                            .foregroundColor(.orange)
                            .fontWeight(.semibold)
                        Text(warning)
                            .font(.caption)
                            .foregroundColor(.secondary)
                    }
                    Spacer()
                    Image(systemName: "chevron.right")
                        .foregroundColor(.secondary)
                        .font(.caption)
                }
                .padding(.vertical, 8)
                .contentShape(Rectangle())
                .onTapGesture {
                    viewModel.navigateToTitrationPlan()
                }
                .accessibilityElement(children: .combine)
                .accessibilityLabel("Upcoming dose change: \(warning)")
                .accessibilityHint("Tap to view dose titration plan")
            }

            // Reminder preferences
            Divider()

            HStack {
                Image(systemName: "bell")
                    .foregroundColor(.secondary)
                Text("Reminder: \(schedule.reminderMinutesBefore) min before")
                    .font(.subheadline)
                    .foregroundColor(.secondary)
            }
        }
        .padding(.vertical, 8)
    }

    private func timeUntilNextDose(_ date: Date) -> String {
        let interval = date.timeIntervalSinceNow

        if interval < 0 { return "Overdue" }

        let hours = Int(interval / 3600)
        let days = hours / 24

        if days > 0 {
            return "in \(days) day\(days == 1 ? "" : "s")"
        } else if hours > 0 {
            return "in \(hours) hour\(hours == 1 ? "" : "s")"
        } else {
            let minutes = Int(interval / 60)
            return "in \(minutes) min"
        }
    }
}
```

```swift
struct PauseScheduleSheet: View {
    let schedule: DoseSchedule
    let onPause: (Date?) -> Void

    @State private var pauseUntil: Date?
    @State private var selectedDuration: PauseDuration = .oneWeek
    @Environment(\.dismiss) private var dismiss

    enum PauseDuration: String, CaseIterable {
        case oneWeek = "1 Week"
        case twoWeeks = "2 Weeks"
        case oneMonth = "1 Month"
        case custom = "Custom Date"
        case indefinite = "Indefinite"

        var date: Date? {
            switch self {
            case .oneWeek:
                return Calendar.current.date(byAdding: .weekOfYear, value: 1, to: Date())
            case .twoWeeks:
                return Calendar.current.date(byAdding: .weekOfYear, value: 2, to: Date())
            case .oneMonth:
                return Calendar.current.date(byAdding: .month, value: 1, to: Date())
            case .custom, .indefinite:
                return nil
            }
        }
    }

    var body: some View {
        NavigationStack {
            Form {
                Section {
                    Picker("Pause Duration", selection: $selectedDuration) {
                        ForEach(PauseDuration.allCases, id: \.self) { duration in
                            Text(duration.rawValue).tag(duration)
                        }
                    }
                    .pickerStyle(.inline)

                    if selectedDuration == .custom {
                        DatePicker(
                            "Resume Date",
                            selection: Binding(
                                get: { pauseUntil ?? Date().addingTimeInterval(7 * 24 * 60 * 60) },
                                set: { pauseUntil = $0 }
                            ),
                            in: Date()...,
                            displayedComponents: .date
                        )
                    }
                } header: {
                    Text("Pause Schedule")
                } footer: {
                    Text("Scheduled doses and reminders will be paused. You can still log doses manually.")
                }
            }
            .navigationTitle("Pause Schedule")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("Cancel") { dismiss() }
                }
                ToolbarItem(placement: .confirmationAction) {
                    Button("Pause") {
                        let resumeDate: Date? = {
                            if selectedDuration == .indefinite {
                                return nil
                            } else if selectedDuration == .custom {
                                return pauseUntil
                            } else {
                                return selectedDuration.date
                            }
                        }()
                        onPause(resumeDate)
                        dismiss()
                    }
                }
            }
        }
        .presentationDetents([.medium])
    }
}
```

```swift
extension MedicationProfileViewModel {
    /// Load active schedule for medication profile
    @MainActor
    func loadActiveSchedule() async {
        activeSchedule = try? scheduleService.fetchActiveSchedule(
            for: medicationProfile
        )
    }

    /// Load schedule modification history
    @MainActor
    func loadScheduleHistory() async {
        scheduleHistory = try? scheduleService.fetchScheduleHistory(
            for: medicationProfile
        ) ?? []
    }

    /// Update existing schedule or create new one
    @MainActor
    func updateSchedule(_ schedule: DoseSchedule) {
        Task {
            do {
                if activeSchedule == nil {
                    // Create new schedule
                    activeSchedule = try scheduleService.createSchedule(
                        for: medicationProfile,
                        config: schedule.toConfig()
                    )
                } else {
                    // Update existing schedule
                    try scheduleService.updateSchedule(schedule)
                    activeSchedule = schedule
                }

                await loadScheduleHistory()
            } catch {
                // Handle error
                print("Failed to update schedule: \(error)")
            }
        }
    }

    /// Pause schedule until specified date
    @MainActor
    func pauseSchedule(until date: Date?) {
        Task {
            guard let schedule = activeSchedule else { return }

            do {
                try scheduleService.pauseSchedule(schedule, until: date)
                await loadActiveSchedule()
                await loadScheduleHistory()
            } catch {
                print("Failed to pause schedule: \(error)")
            }
        }
    }

    /// Resume paused schedule
    @MainActor
    func resumeSchedule() {
        Task {
            guard let schedule = activeSchedule else { return }

            do {
                try scheduleService.resumeSchedule(schedule)
                await loadActiveSchedule()
                await loadScheduleHistory()
            } catch {
                print("Failed to resume schedule: \(error)")
            }
        }
    }

    /// Deactivate schedule permanently
    @MainActor
    func deactivateSchedule() {
        Task {
            guard let schedule = activeSchedule else { return }

            do {
                try scheduleService.deactivateSchedule(schedule)
                activeSchedule = nil
                await loadScheduleHistory()
            } catch {
                print("Failed to deactivate schedule: \(error)")
            }
        }
    }

    /// Navigate to dose titration plan view
    func navigateToTitrationPlan() {
        showDoseTitration = true
    }
}
```

## Implementation Notes

### Technical Considerations
1. **Schedule History Persistence**: Store schedule modifications as append-only log. Never delete history to maintain audit trail. Limit display to last 10 modifications.

2. **Pause vs Deactivate**: Pause is temporary and reversible. Deactivate is permanent (but can create new schedule). Paused schedules retain configuration. Deactivated schedules archived.

3. **Notification Queue Updates**: When schedule modified, paused, or resumed, update NotificationService queue. Cancel existing notifications and reschedule based on new configuration.

4. **Concurrent Schedule Modifications**: Last-write-wins conflict resolution for CloudKit sync. Show warning if schedule modified on another device.

5. **Schedule Summary Next Dose**: Calculate next scheduled dose using ScheduleService. Cache result and recalculate on schedule changes or time-based refresh (every minute).

### Reusable Components
- **SchedulePatternPicker**: From Task 004 onboarding (reuse in edit view)
- **ScheduleService**: Task 002 service for all schedule operations
- **MedicationProfileEditView**: Existing view extended with schedule section

### Edge Cases
1. **No Active Schedule**: Show "Create Dose Schedule" button instead of summary
2. **Multiple Schedules**: Only one active schedule per medication profile allowed. Previous schedules in history.
3. **Indefinite Pause**: Pause with no end date effectively disables notifications until manually resumed
4. **Schedule Deactivation**: Deactivated schedules cannot be resumed - must create new schedule
5. **Custom Patterns**: Phase 1 shows "Coming Soon" for custom patterns

### Accessibility Requirements
- Schedule summary readable by VoiceOver with clear status
- Pause/resume buttons announce current state
- Deactivate confirmation dialog accessible
- Schedule history timeline navigable with VoiceOver
