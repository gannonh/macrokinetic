# Implement comprehensive titration completion workflow with user confirmation dialog

## Objective

Implement critical user-facing integration for dose titration functionality to ensure medical safety. Currently, titration dates pass without any user notification or prompting, creating a medical safety risk where dose changes can be forgotten or missed. This issue implements a comprehensive UX flow with warning banners, dose entry confirmation dialogs, and notification integration to ensure users are properly guided through scheduled dose increases.

## Source Context

From TODO comment in MedicationScheduleSection.swift:21 - expanded after analyzing complete titration UX flow.

## Current Behavior (Problem)

- User creates titration: 1mg → 2mg on Nov 20
- **Nothing happens on Nov 20** - no notification, no prompt
- User must manually navigate to Titration Plan and tap "Complete"
- If forgotten, Add Dose dialog keeps showing old 1mg amount
- Medical safety risk: dose changes can be forgotten or missed

## Technical Approach

### Stream A: Warning Banner Integration
Integrate 30-day advance warning banner in Schedule section using existing `ScheduleService+Titration.swift:getTitrationWarning()` method.

### Stream B: Dose Entry Dialog
Add titration check in dose entry flow (QuickDoseViewModel/DoseService) and create TitrationConfirmationDialog component with three actions: Complete Now, Reschedule, Remind Me Later.

### Stream C: Manual Completion Updates
Update existing "Complete" button behavior in Dose Titration Plan screen to disable/hide after scheduled date passes.

### Stream D: Notification Integration
Coordinate with Issue #260 to add titration notification scheduling with notification actions.

## Implementation Notes

### Medical Safety Rationale
GLP-1 medication dose increases are often delayed due to:
- Side effects (nausea, GI issues)
- Patient tolerance
- Doctor's orders

**User must confirm** dose increase rather than auto-applying. This prevents:
- Accidental overdose if patient delayed increase
- Confusion about which dose to take
- Medical errors from automatic changes
