# Open a PR

Work for the current Issue is complete and ready for review. All tests are passing and swiftlint is clean. 

**ULTRATHINK**

1. Review git history for current feature branch
2. Review GitHub issue associated with the branch
3. Does the PR meet the Issue's acceptance criteria? If not, **alert the user and await further instruction**.
4. Open a Pull Request with detaied description that conforms with best practices
5. Review the spec (docs/spec.md);
6. Recommend spec updates (if any) based on the work scope of the current PR
7. Review implementation plan (docs/implementation-plan.md)
8. Recommend updates to implementation plan (if any) based on the work scope of the current PR
9. Review CLAUDE.md
10. Recommend updates to CLAUDE.md based on learnings or changes made for this PR
