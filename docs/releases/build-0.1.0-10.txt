What's New
- Fasting day toggle: Mark days as fasting to exclude from nutrition calculations

- Concentration chart histogram: Drug concentration now shows as bars instead of line graph
- Centralized nutrition calculations: New NutritionCalculationService as single source of truth

Other Fixes

- Fixed CodeRabbit review issues for error handling and edge cases
- Added 39 new tests for nutrition calculation service
